无线局域网与蜂窝安全

Wireless LAN and cellular security

有线网络从一个端口到另一个端口，无线电信号还会传播到附近的设备。Wi-Fi 保护链路的同时，应用仍有自己的端到端边界。蜂窝课件另用短信说明，数据很短也可能消耗许多控制资源。

A wired network forwards from port to port, while radio signals also reach nearby equipment. Wi-Fi protects a link and applications retain their end-to-end boundaries. The cellular examples show how short messages can consume substantial control resources.

Wi-Fi 从发现接入点到获得 IP

From discovering an access point to getting an IP address

无线局域网（Wireless LAN, WLAN） 的课件例子使用 IEEE 802.11。较早的 a/b/g/n 版本使用不同频段、调制和天线配置。载波侦听多路访问与冲突避免（CSMA/CA） 协调共享信道。设备发送前先判断信道，必要时等待再尝试，而不是每台设备独占无线媒介。

The slides use IEEE 802.11 for a wireless LAN (WLAN). Earlier a/b/g/n versions differ in bands, modulation and antenna behavior. Carrier sense multiple access with collision avoidance (CSMA/CA) coordinates the shared channel. A station checks the channel and can wait before trying to transmit. The radio medium is shared.

在 基础设施模式（Infrastructure Mode） 里，终端关联 接入点（Access Point, AP）。AP 与关联的终端组成一个 基本服务集（Basic Service Set, BSS）。在自组织场景，设备也可能直接交换帧。关联前，终端扫描信道并听 信标帧（Beacon Frame），获取 服务集标识符（Service Set Identifier, SSID） 等信息。选择接入点后还要按网络配置认证、关联，再通过 DHCP 等取得 IP 配置。SSID 只是宣告的名字。

In infrastructure mode, a station associates with an access point (AP). The AP and associated stations form a basic service set (BSS). In an ad hoc network, stations can exchange frames directly. Before association a station discovers APs by scanning channels and reading beacon frames, which include a service set identifier (SSID). It then authenticates and associates as configured and obtains IP settings, for example through DHCP. An SSID is an advertised name.

地址例子。终端访问外网时，无线当前一跳的接收者是 AP，实际要转交的链路目的可能是路由器。802.11 根据帧中的方向标志解释多组地址。设备在同一子网 漫游（Roaming） 时可以保留 IP，交换机从新的路径更新终端的 MAC 所在位置。

Address example. When a station reaches an external network, the AP receives the current wireless hop while a router may be the link destination beyond it. The direction flags determine how fields in a multi-address 802.11 frame are read. A station roaming within one subnet can keep its IP while switches relearn its MAC on a new path.

观察无线帧与保护范围

Observing wireless frames and locating protection

监控模式（Monitor Mode） 可观察选定信道上接收到的 802.11 帧，包括管理帧。混杂模式（Promiscuous Mode） 是在接口本身的接收路径上扩大交付范围，两者看到的帧不完全相同。是否能解读正文还要看链路的加密与认证。

Monitor mode can observe received 802.11 frames on a selected channel, including management frames. Promiscuous mode changes what an interface passes along on its own receive path. The visible frame sets can differ, and readable contents still depend on encryption and authentication.

将 AP 放在防火墙不同侧会影响终端能到达哪些服务，却不会改变电波覆盖。链路加密（Link-Layer Encryption） 只保护相应无线链路。AP 到外网之后的应用数据，仍可由 HTTPS 或 VPN 在各自范围内保护。

Placing the AP on one side or another of a firewall changes which services stations can reach. It does not change where radio signals propagate. Link-layer encryption protects the relevant wireless link. Beyond the AP, HTTPS or a VPN can protect traffic within its own scope.

WEP、WPA、WPA2 和企业认证

WEP, WPA, WPA2 and enterprise authentication

机制 讲义要掌握的设计与局限
WEP（Wired Equivalent Privacy） RC4 根据共享密钥和公开的 24 位 IV 生成密钥流。短 IV 可能重复，同一输入产生相同掩码。CRC-32 主要用于发现传输差错，缺少带秘密的认证。
WPA / TKIP 过渡方案。为兼容旧硬件保留 RC4，改进逐包密钥混合、序列检查与消息完整性码。
WPA2 / CCMP 讲义着重介绍基于 AES 的 CCMP，将计数器加密与 CBC-MAC 类认证组合。保护的是无线数据帧。
Mechanism Design point and limitation
WEP (Wired Equivalent Privacy) RC4 derives a keystream from a shared key and a public 24-bit IV. A small IV can repeat and recreate a mask. CRC-32 is for accidental error detection and does not provide keyed authentication.
WPA / TKIP Transitional design. Retains RC4 for older hardware and improves per-packet key mixing, sequence checks and the message integrity code.
WPA2 / CCMP The slides stress AES-based CCMP, which combines counter-mode encryption with CBC-MAC-based authentication for data frames.

预共享密钥（Pre-Shared Key, PSK） 是家用等场景的一种方式，弱口令会降低保密性。企业场景可以经 802.1X 控制接入。终端与 AP 之间用 EAPOL（EAP over LAN） 传 EAP（Extensible Authentication Protocol） 消息，AP 常经 RADIUS 与后端认证服务通信。认证完成以后，才建立和使用相应的数据保护状态。

A pre-shared key (PSK) is one option for home networks. A weak passphrase undermines confidentiality. Enterprise networks can use 802.1X for access control. The station and AP carry Extensible Authentication Protocol (EAP) over LAN using EAPOL, and the AP can talk to a backend authentication server over RADIUS. Successful authentication precedes use of the relevant data protection state.

把 帧保密、接入身份 与 空口可用性 分开。MAC 地址便于识别转发对象，身份要由认证协议证明。即使数据帧加密，共享信道仍可能被干扰或过度占用。课堂用 RTS/CTS 说明协调空口的控制消息也关系到可用性。

Separate frame confidentiality, access identity and availability of the radio channel. MAC addresses identify forwarding destinations, while authentication establishes identity. A shared channel can be interrupted or overused even when data frames are encrypted. RTS/CTS illustrates why media coordination also affects availability.

蜂窝短信的路由与信令

Cellular SMS routing and signaling

讲义用传统 GSM/SMS 结构来解释 SMS 交付。一个 SMS 可由终端或 外部短信实体（ESME） 发起，进入 短信中心（Short Message Service Center, SMSC）。SMSC 负责暂存与路由。HLR（Home Location Register） 包含长期订阅信息，VLR（Visitor Location Register） 保存当前服务区的相关信息。MSC（Mobile Switching Center） 处理交换和路由，基站（Base Station, BS） 完成空口交付。

The slides illustrate SMS delivery using a traditional GSM architecture. A phone or an external short message entity (ESME) submits a message to a Short Message Service Center (SMSC), which stores and routes it. The Home Location Register (HLR) holds long-term subscription data, while the Visitor Location Register (VLR) holds serving-area information. A Mobile Switching Center (MSC) manages switching and routing, and a base station (BS) delivers over the air.

外部入口 → SMSC → 获取路由信息 → MSC → 基站 → 手机。

External input → SMSC → routing lookup → MSC → base station → handset.

控制信道（Control Channel, CCH） 承载寻呼、接入、认证等信令，和承载通话等业务的数据资源有区别。课件中终端在 PCH（Paging Channel） 收到提示，经 RACH（Random Access Channel） 响应。系统为后续认证和交付分配 SDCCH（Standalone Dedicated Control Channel），可能包含临时身份更新。

A control channel (CCH) carries signaling such as paging, access and authentication, distinct from the resources for user traffic such as a call. In the slides the phone is notified on the paging channel (PCH) and responds over the random access channel (RACH). The system can assign a standalone dedicated control channel (SDCCH) for authentication and delivery, potentially including a temporary identity update.

容量判断。一条短短信仍可能需要多个信令步骤。SMSC 缓冲区已满时可能排队或丢弃消息。空口控制资源忙时，数据负载看起来小也可能处理不动新会话。故障分析应分别观察消息队列、空口信令会话和业务流量。这里的信道名称对应课件的传统系统。

Capacity reasoning. A short SMS can still require multiple signaling steps. A full SMSC queue can delay or drop messages. Busy air-interface control resources can limit new sessions even with small payloads. Examine message queues, signaling sessions and user traffic separately. The named channels here follow the traditional system shown in class.
