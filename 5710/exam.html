PRG 从短种子生成长串

PRGs stretch a short seed into a longer string

一个 均匀随机的 n 位串（uniform n-bit string）从 2ⁿ 种结果中等概率取一个，每一种的概率是 2⁻ⁿ。伪随机生成器（pseudorandom generator, PRG）G 把 s 位随机种子（seed）扩展成 ℓ 位输出，且 ℓ > s。同一个种子总产生同一个输出，所以可生成的长串最多 2ˢ 个。

A uniform n-bit string takes each of its 2ⁿ possible values with probability 2⁻ⁿ. A pseudorandom generator (PRG) G stretches a random s-bit seed into ℓ bits with ℓ > s. The same seed always yields the same output, so at most 2ˢ long strings can occur.

给你一条长串，安全性问题就是能否用可行的计算识别出它来自 G(seed)？能检查所有种子的对手总可以判定输出是否在这最多 2ˢ 条串里。安全的 PRG 要求高效区分器（efficient distinguisher）只得到可忽略的区分优势。可忽略（negligible）表示随安全参数增长，比任何逆多项式更快趋近于零。

The security question is whether feasible computation can tell that a long string came from G(seed). Exhaustively checking every seed identifies membership in the output set. A secure PRG gives every efficient distinguisher only negligible advantage. A negligible quantity eventually decreases faster than every inverse polynomial in the security parameter.

写题时，用同一个布尔测试 D 跑两次思想实验。真实实验（real experiment）输入 G(Uₛ)，理想实验（ideal experiment）输入 Uℓ。定义 Adv = |Pr[D(真实)=1] − Pr[D(理想)=1]|。两个概率都针对同一个事件 D 输出 1。等概率选择世界且把输出 1 对应到概率较大的世界时，猜对率是 1/2 + Adv/2。

Run the same Boolean test D in two thought experiments. The real input is G(Uₛ), and the ideal input is Uℓ. Define Adv = |Pr[D(real)=1] − Pr[D(ideal)=1]|. Both probabilities refer to the same event, D returning 1. With equally likely worlds, mapping output 1 to the world where it is more likely gives success probability 1/2 + Adv/2.

例题 1 · 三个比特分别均匀，为什么仍可区分？

Example 1 · Each bit is balanced. Why can we distinguish the output?

取两位均匀种子 (a,b)，定义 G(a,b) = (a,b,a ⊕ b)。异或（XOR）相同为 0、不同为 1。测试 D 看到 (x,y,z) 时，只检查 z = x ⊕ y，成立输出 1。

Take a uniform two-bit seed (a,b) and define G(a,b) = (a,b,a ⊕ b). XOR gives 0 for equal bits and 1 for different bits. Given (x,y,z), test D outputs 1 exactly when z = x ⊕ y.

例题 2 · 三个不同输入有多大概率撞值？

Example 2 · How likely is a collision among three distinct inputs?

输出空间有八个值，在同一张表上查询三个彼此不同的输入。测试 D 在至少一对输出相同时输出 1。先算随机函数里三次都不同的概率，第一次随便取，第二次避开 1 个值，第三次避开 2 个。

The output space has eight values. Query three distinct inputs in the same table. D outputs 1 if at least two outputs match. For a random function, first calculate the chance all three differ. The first output may be anything, the second avoids one value, and the third avoids two.

Pr[都不同] = 1 × (7/8) × (6/8) = 21/32，因此 Pr[D(随机函数)=1] = 11/32。随机置换的三个输出一定不同，Pr[D(随机置换)=1] = 0。用这个事件比较两种理想表，概率差为 11/32。给出具体 PRF 或 PRP 构造时，再用同一个事件求构造侧的概率。

Pr[all distinct] = 1 × (7/8) × (6/8) = 21/32, so Pr[D(random function)=1] = 11/32. A random permutation always gives three distinct outputs, so Pr[D(random permutation)=1] = 0. The gap for this event is 11/32. If given a concrete PRF or PRP construction, calculate its probability for that same event.

从伪随机性到一次性语义安全

From pseudorandomness to one-time semantic security

在一次性语义安全（one-time semantic security）的游戏里，观察者自选两条等长消息，看到其中一条的密文后猜选择位。若密文是 C = M ⊕ R 且 R 为新抽取的均匀掩码（pad），对任何给定的 C 和 M，都恰好有一个 R 能使等式成立。把 R 换为安全 PRG 的同长度输出时，若能有效区分两条消息，便能借同一个测试区分 PRG 输出与均匀串。

In the one-time semantic security game, an observer chooses two equal-length messages and guesses which one was encrypted. If C = M ⊕ R with a fresh uniform pad R, each fixed C and M has exactly one compatible R. Replacing R with an equal-length output of a secure PRG preserves computational security. An effective message distinguisher would also distinguish the PRG output from a uniform string.

以 C = 110 为例。M₀ = 010 时需要 R = 100，M₁ = 111 时需要 R = 001。任一掩码都以 1/8 出现，所以两边出现这个密文的概率一样。这里的前提是每条消息使用独立掩码，复用情形见 例题 5。

Take C = 110. The pad is 100 for M₀ = 010 and 001 for M₁ = 111. Each pad occurs with probability 1/8, so the two worlds give the same probability for this ciphertext. This reasoning relies on independent pads for messages. See Example 5 for reuse.

分组密码、模式、IV 和计数器

Block ciphers, modes, IVs and counters

分组密码（block cipher）用密钥 K 把一个固定长度的块变成另一个同长度块，写作 Eₖ，解密写作 Dₖ。工作模式（mode of operation）规定长消息如何分块、每块的输入怎样连接。用 Pᵢ 表示第 i 个明文块、Cᵢ 表示密文块。⊕ 表示逐位异或，可用 (A ⊕ B) ⊕ B = A 消去同一掩码。

A block cipher maps one fixed-size block to another under key K. Write Eₖ for encryption and Dₖ for decryption. A mode of operation determines how a long message is divided and how the block inputs are formed. Pᵢ and Cᵢ denote plaintext and ciphertext blocks. ⊕ is bitwise XOR, so (A ⊕ B) ⊕ B = A cancels a repeated mask.

初始化向量（initialization vector, IV）是某些模式的起始输入，可以随密文传送。Nonce 强调在同一密钥下只使用一次。CBC 和 CFB 要求加密时的 IV 不可预测。OFB 的 IV 要唯一。CTR 要保证同一密钥下的每一个计数器块（counter block）唯一，包括不同消息的块号范围。IV/nonce 与秘密密钥各自承担不同角色。

An initialization vector (IV) is a starting input that may be transmitted with ciphertext. A nonce emphasizes one use per key. CBC and CFB require an unpredictable IV for encryption. OFB requires a unique IV. CTR requires every counter block to be unique under one key, across all messages and their counter ranges. IVs or nonces and secret keys serve distinct roles.

例题 5 · 同一个起始值用两次会暴露什么？

Example 5 · What does reusing a starting value reveal?

CBC 在同一密钥和同一 IV 下，若两条消息的第一块都是 6，第一块密文都等于 E(6 ⊕ 1)=A。若前两块也相同，两块密文都会相同。这个现象暴露相同前缀（equal prefixes），因为初始状态与每步输入都相同。

For CBC under the same key and IV, two messages beginning with 6 both start with ciphertext E(6 ⊕ 1)=A. If their first two plaintext blocks match, both ciphertext blocks match. This reveals equal prefixes, since the starting state and the inputs along the shared prefix match.

CTR 若在同一密钥下重复首个计数器块 1，两条消息都会用掩码 S = E(1) = 4。消息块 6 和 A 分别产生 6 ⊕ 4 = 2、A ⊕ 4 = E（此处 E 是十六进制的 14）。2 ⊕ E = C，正好等于 6 ⊕ A = C。代数上 (P ⊕ S) ⊕ (P′ ⊕ S) = P ⊕ P′，掩码被消去。OFB 重复 IV 也会从头重复掩码。

If CTR repeats counter block 1 under the same key, both messages use mask S = E(1) = 4. Blocks 6 and A give 6 ⊕ 4 = 2 and A ⊕ 4 = E (hex E is 14). 2 ⊕ E = C, just as 6 ⊕ A = C. Algebraically, (P ⊕ S) ⊕ (P′ ⊕ S) = P ⊕ P′ because the masks cancel. Reusing the OFB IV also repeats masks from the start.

取模、互质与模逆

Remainders, coprimality and modular inverses

17 mod 5 = 2 表示 17 除以 5 余 2。17 ≡ 2 (mod 5) 表示两数对 5 取余相同。最大公约数（greatest common divisor, gcd）是两个数共同的最大正因子。gcd(e, φ(n)) = 1 表示两者互质（coprime），此时 e 在模 φ(n) 下有模逆（modular inverse）d，满足 ed ≡ 1 (mod φ(n))。

17 mod 5 = 2 means 17 leaves remainder 2 on division by 5. 17 ≡ 2 (mod 5) means both numbers have that same remainder. The greatest common divisor (gcd) is the largest positive divisor shared by two numbers. gcd(e, φ(n)) = 1 means the numbers are coprime, so e has a modular inverse d satisfying ed ≡ 1 (mod φ(n)).

质数 p、q 互异时，欧拉函数（Euler’s totient）φ(pq) = (p−1)(q−1)。它数的是 1 到 n 里与 n 互质的整数。RSA 里 找私钥指数 d 用 φ(n)，处理消息、密文和签名用 n。算大幂先算平方，每一步取余，最后拼出所需指数，这叫平方乘法（square-and-multiply）。

For distinct primes p and q, Euler’s totient is φ(pq) = (p−1)(q−1). It counts integers from 1 through n coprime to n. For RSA, find the private exponent d using φ(n), and compute message, ciphertext and signature powers modulo n. Repeatedly square with reductions and combine the needed powers. This is square-and-multiply.

例题 6 · 生成 RSA 密钥，再加密和解密

裸 RSA、OAEP 和数字签名各解决什么

裸 RSA（textbook RSA）直接计算 c=mᵉ mod n。同一公钥下同一个整数总给同一个密文，这种确定性（determinism）与选择明文安全的目标冲突。RSA-OAEP 在做 RSA 运算前用随机种子和掩码编码消息，使重复加密同一消息通常得到不同密文。

Textbook RSA computes c=mᵉ mod n directly. The same integer and public key always give the same ciphertext. This determinism conflicts with the goal of chosen-plaintext security. RSA-OAEP first encodes the message with a random seed and masks, so encryptions of the same message usually differ.

群、生成元与 Diffie–Hellman 密钥交换

Groups, generators and Diffie–Hellman key exchange

这里的群（group）是一组可做模乘法的数。结果仍在组内，1 是单位元，每个元素都有乘法逆元。一个循环群（cyclic group）里的元素都可写成某个生成元 g 的幂。g 的阶（order of g）是让 gq ≡ 1 (mod p) 成立的最小正指数 q，所以 g 的幂每 q 步循环一次。

Here a group is a set of numbers closed under modular multiplication, with identity 1 and a multiplicative inverse for every element. In a cyclic group, all elements are powers of a generator g. The order of g is the smallest positive exponent q with gq ≡ 1 (mod p), so its powers cycle every q steps.

Diffie–Hellman（DH）让双方各保留一个秘密指数 a、b，交换公开值 A=gᵃ mod p 和 B=gᵇ mod p。一方算 Bᵃ，另一方算 Aᵇ，都得到 gᵃᵇ。算群元素取模 p，化简 g 的指数可以对 q 取模。使用 DH 建立带身份的连接时，还要认证交换的公钥或握手消息。

In Diffie–Hellman (DH), each side keeps its secret exponent a or b and exchanges a public value A=gᵃ mod p or B=gᵇ mod p. They compute Bᵃ and Aᵇ, respectively, and both get gᵃᵇ. Reduce group values modulo p and exponents of g modulo q. Authenticated key exchange also authenticates the exchanged public values or handshake messages.

A random Z in the decisional problem can equal the true shared value by chance, so security compares output probabilities in two experiments. Chosen-plaintext security (IND-CPA) compares encryptions of equal-length plaintexts. In public-key encryption the observer can encrypt with the public key. Chosen-ciphertext security (IND-CCA), in the standard adaptive game, also allows decrypting other ciphertexts before and after the challenge, except for the challenge ciphertext itself. Malleability describes how changing a ciphertext can produce a predictably related plaintext. A confidentiality-only construction with this property fails the stronger CCA goal.

ElGamal 怎样把 DH 共享值用来加密

How ElGamal uses a DH shared value for encryption

收件人保有私钥 x，公布 h=gˣ。发送者为每次加密独立选择随机指数 r（ephemeral exponent），得到 c₁=gʳ 和共享掩码 S=hʳ。消息代表值 m 在群内，c₂=m·S。收件人用 c₁ˣ=S 和逆元 S⁻¹ 取回 m=c₂·S⁻¹。这是 DH 的两个临时公开值与共享值关系在加密里的应用，其中收件人的 h 来自固定私钥。

The recipient keeps private x and publishes h=gˣ. The sender independently chooses an ephemeral exponent r for each encryption, producing c₁=gʳ and shared mask S=hʳ. For a message representative m in the group, c₂=m·S. The recipient computes c₁ˣ=S and its inverse S⁻¹ to recover m=c₂·S⁻¹. This uses the DH relation between two public values and a shared value. The recipient’s h comes from the long-term private key.

在满足 DDH 假设的群里，可把 hʳ 与独立随机群元素进行比较。若掩码真的是均匀群元素，那么对任意固定 m，乘以 m 只是把群元素重新排列，所以 m·S 仍均匀。这个推理说明 ElGamal 的 IND-CPA 保密性来自哪里。原始 ElGamal 具有可塑性，完整的 CCA 安全需要使用满足更强定义的构造。

Under the DDH assumption, compare hʳ with an independent random group element. With a uniform mask, multiplication by any fixed m permutes the group, so m·S is still uniform. This explains the source of ElGamal’s IND-CPA confidentiality. Textbook ElGamal is malleable. CCA security requires a construction that meets the stronger definition.

摘要与哈希的三个安全性质

Digests and the three hash security properties

哈希函数（hash function）H 把可变长度的输入映射成固定 n 位的摘要（digest）。同样的输入字节总得到同一个摘要。输入的可能性比摘要多，所以必然存在两个不同输入得到相同摘要。安全性质关心的是，在给定限制下找到它们有多难。

A hash function H maps inputs of varying length to a fixed n-bit digest. Identical input bytes always produce the same digest. There are more possible inputs than digests, so distinct inputs with the same digest must exist. Security is about how hard it is to find them under the stated constraints.

例题 11 · 重复拼接摘要有没有增加抗碰撞强度？

Example 11 · Does repeating a digest increase collision resistance?

|| 表示按顺序拼接（concatenation）。设 J(x)=H(x)||H(x)。如果 H 给出三位摘要 101，J 输出 101101。虽然有六个位，后半完全由前半决定，因此最多 2³=8 种可能输出。一般情形下，J(x)=J(x′) 恰好当 H(x)=H(x′)。

|| denotes ordered concatenation. Let J(x)=H(x)||H(x). A three-bit H digest 101 yields 101101 under J. The output has six bits but the first half determines the second, leaving at most 2³=8 possibilities. In general, J(x)=J(x′) holds exactly when H(x)=H(x′).

所以 J 的碰撞还是 H 的同一对碰撞。构造题还要区分编码与哈希。把字段 (AB,C) 和 (A,BC) 直接拼接，两组都得到字节串 ABC，哈希接到的输入已经一样。带长度的编码能让两组字段对应不同字节串，然后才能讨论真正的哈希碰撞。

A collision for J is the same pair as a collision for H. In construction questions, separate encoding from hashing. Concatenating the fields (AB,C) and (A,BC) directly gives ABC in each case. The hash sees identical input bytes. A length-aware encoding makes the byte strings distinct so the hash collision question is well defined.

MAC 的标签验证什么

What a MAC verifies

消息认证码（message authentication code, MAC）用双方共享的秘密密钥 K，计算消息 M 的短标签（tag）T = MACₖ(M)。接收者运行验证算法，确定标签与收到的字节串在同一密钥下匹配。普通哈希只需知道消息即可计算，MAC 的安全性来自秘密密钥。MAC 验证完整性和持钥方认证，消息内容需要用加密保护。

A message authentication code (MAC) uses a shared secret key K to compute a short tag T = MACₖ(M) on message M. The receiver verifies that the tag matches the received bytes under the same key. An ordinary hash needs only the message, while MAC security relies on a shared secret. A MAC checks integrity and authenticates a holder of the key. Encryption protects the message content.

不可伪造性（unforgeability）的考试模型允许观察者取得自己选的消息的标签，要求它仍无法为新的消息生成一个有效标签。理想 t 位标签的一次独立猜中概率是 2⁻ᵗ，例如 t=16 时是 1/65536 ≈ 0.00153%。真实构造还需要分析算法本身、标签长度和使用条件。

In the exam model of unforgeability, an observer can obtain tags on messages it chooses and should still be unable to produce a valid tag for a new message. An independent guess for an ideal t-bit tag succeeds with probability 2⁻ᵗ. At t=16 this is 1/65536 ≈ 0.00153%. Real schemes also depend on the algorithm, tag length, and conditions of use.

例题 13 · 手算两块 CBC-MAC，并交换块的顺序

Example 13 · Calculate a two-block CBC-MAC and swap the blocks

CBC-MAC 从全零状态 X₀=0 开始，用 Xᵢ=Eₖ(Xᵢ₋₁ ⊕ Mᵢ) 连续处理每块，只取最后的 Xₙ 为标签。基本构造的安全条件之一是同一密钥下认证固定长度的消息。需要处理可变长度时，可选适用于该用途的标准构造，例如 CMAC。

CBC-MAC starts from the zero state X₀=0, processes each block with Xᵢ=Eₖ(Xᵢ₋₁ ⊕ Mᵢ), and returns only the last state Xₙ as the tag. The basic scheme’s security uses a fixed message length under the key. For variable-length messages, use a scheme designed for that purpose, such as CMAC.

沿用例题 3 的四位 E(x)=(x+3) mod 16。对两块 (6,A)，X₁=E(0 ⊕ 6)=9，X₂=E(9 ⊕ A)=E(3)=6，标签为 6。改顺序为 (A,6)，X₁=E(A)=D，X₂=E(D ⊕ 6)=E(B)=E（最后的 E 是十六进制 14），标签变为 E。

Reuse the four-bit E(x)=(x+3) mod 16 from Example 3. For (6,A), X₁=E(0 ⊕ 6)=9 and X₂=E(9 ⊕ A)=E(3)=6, yielding tag 6. Swap to (A,6). Now X₁=E(A)=D and X₂=E(D ⊕ 6)=E(B)=E (the final E is hex 14), yielding tag E.

验证端按收到的块和顺序重算，本题的 (A,6) 配标签 6 就不会通过。分析任意设计时，明确序列化如何绑定字段边界、顺序和长度。前一节的 (AB,C) 与 (A,BC) 问题也适用于待认证字段。

The verifier recomputes over the received blocks in order, so (A,6) with tag 6 does not pass this example. For any design, say how serialization binds field boundaries, order and length. The (AB,C) versus (A,BC) encoding issue also applies to authenticated fields.

HMAC 的两层哈希

The two hash layers in HMAC

HMAC（hash-based message authentication code）先使密钥变成哈希压缩函数的块长 B。超过 B 的密钥先哈希，较短的在右侧补零，得到 K₀。HMAC-SHA-256 的 B 是 64 字节，内层摘要是 32 字节。ipad 和 opad 分别是重复 B 次的字节 0x36 和 0x5c。

HMAC (hash-based message authentication code) normalizes the key to the hash block length B. Hash a key longer than B, and right-pad a shorter key with zeros to make K₀. HMAC-SHA-256 uses B = 64 bytes and a 32-byte inner digest. ipad and opad repeat bytes 0x36 and 0x5c, respectively, B times.

先算内层 I = H((K₀ ⊕ ipad) || M)，再算外层 T = H((K₀ ⊕ opad) || I)。外层处理的是内层摘要原始字节，计算题用十六进制显示这些字节。把十六进制字符本身当输入会改变结果。

First compute the inner digest I = H((K₀ ⊕ ipad) || M), then the outer digest T = H((K₀ ⊕ opad) || I). The outer layer receives the raw inner digest bytes. Exercises display these in hexadecimal. Using the hexadecimal characters as input would change the result.

GCM 的计数器、GHASH 和长度块

GCM counters, GHASH and the length block

GCM（Galois/Counter Mode）用计数器模式加密明文，用 GHASH 累积关联数据 A 和密文 C，再用一个 AES 输出掩盖哈希结果形成标签。对 96 位 IV，初始块 J₀=IV || 0³¹ || 1。Eₖ(J₀) 给标签使用，第一个加密掩码从 inc32(J₀) 开始，其中 inc32 递增末尾 32 位。H=Eₖ(0¹²⁸) 是 GHASH 的子密钥。

GCM (Galois/Counter Mode) encrypts with counter mode, folds associated data A and ciphertext C into GHASH, then masks the result with another AES output to form the tag. For a 96-bit IV, the initial block is J₀=IV || 0³¹ || 1. Eₖ(J₀) masks the tag. The first encryption mask uses inc32(J₀), which increments the low 32 bits. The GHASH subkey is H=Eₖ(0¹²⁸).

GHASH 的输入依次是补齐到整块的 A、补齐的 C、一个长度块。长度块把 A 和 C 补齐前的位数分别编码成 64 位后拼起来。令这些输入块为 Xᵢ，从 Y₀=0 开始算 Yᵢ=(Yᵢ₋₁ ⊕ Xᵢ)·H。点乘在有限域 GF(2¹²⁸) 中做，先按二元多项式相乘，再按 x¹²⁸+x⁷+x²+x+1 约简。标签取 Eₖ(J₀) ⊕ Y_final 的最高 t 位。标签核对失败时应拒绝消息，同一密钥下每条消息的 IV 要唯一。

GHASH processes block-padded A, block-padded C, and a length block. The length block concatenates the original bit lengths of A and C as two 64-bit integers. For those blocks Xᵢ, start with Y₀=0 and compute Yᵢ=(Yᵢ₋₁ ⊕ Xᵢ)·H. Multiply in GF(2¹²⁸), using binary polynomials reduced by x¹²⁸+x⁷+x²+x+1. The tag is the most significant t bits of Eₖ(J₀) ⊕ Y_final. A failed tag check means reject. Each message needs a unique IV under the key.
