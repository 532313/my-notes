PRG 从短种子生成长串

PRGs stretch a short seed into a longer string

一个 均匀随机的 n 位串（uniform n-bit string）从 2ⁿ 种结果中等概率取一个，每一种的概率是 2⁻ⁿ。伪随机生成器（pseudorandom generator, PRG）G 把 s 位随机种子（seed）扩展成 ℓ 位输出，且 ℓ > s。同一个种子总产生同一个输出，所以可生成的长串最多 2ˢ 个。

A uniform n-bit string takes each of its 2ⁿ possible values with probability 2⁻ⁿ. A pseudorandom generator (PRG) G stretches a random s-bit seed into ℓ bits with ℓ > s. The same seed always yields the same output, so at most 2ˢ long strings can occur.

给你一条长串，安全性问题就是能否用可行的计算识别出它来自 G(seed)？能检查所有种子的对手总可以判定输出是否在这最多 2ˢ 条串里。安全的 PRG 要求高效区分器（efficient distinguisher）只得到可忽略的区分优势。可忽略（negligible）表示随安全参数增长，比任何逆多项式更快趋近于零。

The security question is whether feasible computation can tell that a long string came from G(seed). Exhaustively checking every seed identifies membership in the output set. A secure PRG gives every efficient distinguisher only negligible advantage. A negligible quantity eventually decreases faster than every inverse polynomial in the security parameter.

写题时，用同一个布尔测试 D 跑两次思想实验。真实实验（real experiment）输入 G(Uₛ)，理想实验（ideal experiment）输入 Uℓ。定义 Adv = |Pr[D(真实)=1] − Pr[D(理想)=1]|。两个概率都针对同一个事件 D 输出 1。等概率选择世界且把输出 1 对应到概率较大的世界时，猜对率是 1/2 + Adv/2。

Run the same Boolean test D in two thought experiments. The real input is G(Uₛ), and the ideal input is Uℓ. Define Adv = |Pr[D(real)=1] − Pr[D(ideal)=1]|. Both probabilities refer to the same event, D returning 1. With equally likely worlds, mapping output 1 to the world where it is more likely gives success probability 1/2 + Adv/2.

例题 1 · 三个比特分别均匀，为什么仍可区分？

Example 1 · Each bit is balanced. Why can we distinguish the output?

取两位均匀种子 (a,b)，定义 G(a,b) = (a,b,a ⊕ b)。异或（XOR）相同为 0、不同为 1。测试 D 看到 (x,y,z) 时，只检查 z = x ⊕ y，成立输出 1。

Take a uniform two-bit seed (a,b) and define G(a,b) = (a,b,a ⊕ b). XOR gives 0 for equal bits and 1 for different bits. Given (x,y,z), test D outputs 1 exactly when z = x ⊕ y.

Thus the advantage is 1/2 and guessing succeeds with probability 3/4. Look at the third bit alone and it is 0 twice and 1 twice. The test uses its correlation with the first two bits.

查询接口（oracle）表示题目允许你输入 x 并拿到输出。秘密密钥或随机表在同一轮实验里固定。随机函数会在第一次见到一个输入时为它独立抽值，之后沿用这个值。普通 PRP 实验以正向查询为例，题目给出正向与逆向查询时，要和同时提供逆表的随机置换比较。

A query interface (oracle) lets you submit x and receive an answer. The secret key or random table is fixed within a trial. A random function picks an independent value on the first query at an input and reuses that value on repeats. A basic PRP experiment uses forward queries. When the question also offers inverse queries, use a random permutation with its inverse as the ideal interface.

例题 2 · 三个不同输入有多大概率撞值？

Example 2 · How likely is a collision among three distinct inputs?

输出空间有八个值，在同一张表上查询三个彼此不同的输入。测试 D 在至少一对输出相同时输出 1。先算随机函数里三次都不同的概率，第一次随便取，第二次避开 1 个值，第三次避开 2 个。

The output space has eight values. Query three distinct inputs in the same table. D outputs 1 if at least two outputs match. For a random function, first calculate the chance all three differ. The first output may be anything, the second avoids one value, and the third avoids two.

Pr[都不同] = 1 × (7/8) × (6/8) = 21/32，因此 Pr[D(随机函数)=1] = 11/32。随机置换的三个输出一定不同，Pr[D(随机置换)=1] = 0。用这个事件比较两种理想表，概率差为 11/32。给出具体 PRF 或 PRP 构造时，再用同一个事件求构造侧的概率。

Pr[all distinct] = 1 × (7/8) × (6/8) = 21/32, so Pr[D(random function)=1] = 11/32. A random permutation always gives three distinct outputs, so Pr[D(random permutation)=1] = 0. The gap for this event is 11/32. If given a concrete PRF or PRP construction, calculate its probability for that same event.

从伪随机性到一次性语义安全

From pseudorandomness to one-time semantic security

在一次性语义安全（one-time semantic security）的游戏里，观察者自选两条等长消息，看到其中一条的密文后猜选择位。若密文是 C = M ⊕ R 且 R 为新抽取的均匀掩码（pad），对任何给定的 C 和 M，都恰好有一个 R 能使等式成立。把 R 换为安全 PRG 的同长度输出时，若能有效区分两条消息，便能借同一个测试区分 PRG 输出与均匀串。

In the one-time semantic security game, an observer chooses two equal-length messages and guesses which one was encrypted. If C = M ⊕ R with a fresh uniform pad R, each fixed C and M has exactly one compatible R. Replacing R with an equal-length output of a secure PRG preserves computational security. An effective message distinguisher would also distinguish the PRG output from a uniform string.

以 C = 110 为例。M₀ = 010 时需要 R = 100，M₁ = 111 时需要 R = 001。任一掩码都以 1/8 出现，所以两边出现这个密文的概率一样。这里的前提是每条消息使用独立掩码，复用情形见 例题 5。

Take C = 110. The pad is 100 for M₀ = 010 and 001 for M₁ = 111. Each pad occurs with probability 1/8, so the two worlds give the same probability for this ciphertext. This reasoning relies on independent pads for messages. See Example 5 for reuse.

2021–22 Q3 不可能输出与互补输入 Impossible outputs and complementary inputs

IERG4150 · PDF p. 4 · 题意改述 / Paraphrased question

(a)

题意 / Problem in brief

G 把 λ 位随机种子变为 2λ 位。集合 S 只含 G 生成不了的串。计算“输出属于 S”这个测试的优势，并说明它为何不自动推翻 PRG。

G stretches a λ-bit seed to 2λ bits. S contains only strings outside its image. Find the advantage of the membership test and explain why it does not invalidate every PRG.

解题步骤 / Derivation

  1. 真实输出一定在 G 的像集里，而 S 与像集不相交。故 Pr[D(real)=1]=0。

    Real outputs always belong to the image of G, which is disjoint from S. Therefore Pr[D(real)=1]=0.

  2. 理想世界对 2^(2λ) 个串等概率抽样。S 有 |S| 个串，概率为 |S|/2^(2λ)。优势取绝对差，仍等于 |S|/2^(2λ)。

    The ideal source samples uniformly from 2^(2λ) strings. Membership in S has probability |S|/2^(2λ), which is also the absolute probability gap.

  3. 题设的 S 可以只是补集的一部分。若取完整补集，G 最多有 2^λ 种输出，优势至少为 1−2^(−λ)。可高效识别的 S 才能产生有效区分器；把完整补集硬编码或枚举所有种子通常需要指数规模。

    S can be only part of the complement. Using the whole complement gives at least 1−2^(−λ) because G has at most 2^λ outputs. An efficient test requires an efficiently recognizable set. Hard-coding the whole complement or enumerating every seed typically needs exponential resources.

(b)

题意 / Problem in brief

对输入取按位补码 x̄。判断 F′ₖ(x)=Fₖ(x)||Fₖ(x̄) 是否是安全 PRF，并计算区分优势。

For the bitwise complement x̄, determine whether F′ₖ(x)=Fₖ(x)||Fₖ(x̄) is a PRF and compute a distinguishing gap.

解题步骤 / Derivation

  1. 取非空 x，则 x 和 x̄ 是两个不同输入。记 A=Fₖ(x), B=Fₖ(x̄)，真实输出分别为 A||B 和 B||A。检查第二个结果等不等于第一个结果交换两半，真实概率为 1。

    For nonempty x, x and x̄ differ. Let A=Fₖ(x), B=Fₖ(x̄). The real responses are A||B and B||A, so a test for swapped halves succeeds with probability 1.

  2. 设每半 ℓ 位。理想的两个 2ℓ 位结果独立。固定第一个输出后，第二个只有一种能通过，概率为 2^(−2ℓ)。优势 1−2^(−2ℓ)，因此 F′ 不安全。

    Let each half have ℓ bits. The two ideal 2ℓ-bit responses are independent. Once the first is fixed, one second response passes, with probability 2^(−2ℓ). The gap is 1−2^(−2ℓ); F′ is insecure.

2021–22 Q4(a) 先置换随机掩码的加密 Encrypting the random mask

IERG4150 · PDF p. 5 · 题意改述 / Paraphrased question

(a)

题意 / Problem in brief

每次均匀抽取 r，发送 (x,y)=(Fₖ(r),r⊕m)，F 为 λ 位 PRP。给出解密并判断 CPA 安全。

Each encryption samples uniform r and returns (Fₖ(r),r⊕m) for a λ-bit PRP F. Derive decryption and decide CPA security.

解题步骤 / Derivation

  1. 持有 k 时先算 r=Fₖ⁻¹(x)，再算 m=y⊕r。因为 (r⊕m)⊕r=m，顺序正好撤销加密步骤。

    With k, first recover r=Fₖ⁻¹(x), then m=y⊕r. The identity (r⊕m)⊕r=m reverses the masking.

  2. 把 Fₖ 换成随机置换 π。只要各次 r 未重复，π(r) 就是一组从未用过的随机标签，且和 r 的具体取值无关。在理想比较里直接给新标签与均匀的 y=r⊕m；遇到 r 碰撞才需要修正模拟。

    Replace Fₖ by a random permutation π. As long as r values do not repeat, π gives fresh unused labels independently of the specific mask values. An ideal comparison gives such labels and a uniform y=r⊕m. The simulation can deviate only on a repeated r.

  3. 第 i 次至多遇到 i−1 个旧 r，概率至多 (i−1)/2^λ。q 次查询的并合界是 q(q−1)/(2·2^λ)。理想输出对等长 m 隐藏选择位，两个世界各加置换替换误差与碰撞界；多项式 q 下可忽略。因此在给定 PRP 假设下为 CPA 安全。

    At query i there are at most i−1 old masks, so the repeat probability is at most (i−1)/2^λ. The union bound for q queries is q(q−1)/(2·2^λ). The ideal replies hide the message choice. Add the permutation-replacement and repeat errors for each side; for polynomial q these are negligible under the PRP assumption.

2022–23 Q1 种子分段与两轮 Feistel Seed splitting and two-round Feistel

IERG4150 · PDF p. 3 · 题意改述 / Paraphrased question

(a)

题意 / Problem in brief

G 将 λ 位扩成 3λ 位。H 对独立的两半 sL||sR 返回 sL||G(sR)。证明 H 是安全 PRG。

G expands λ bits to 3λ. H takes sL||sR and returns sL||G(sR). Prove that H is a secure PRG.

解题步骤 / Derivation

  1. H 读入 2λ 位、输出 4λ 位，满足伸长。均匀的 2λ 位种子分成两半后，sL、sR 各自均匀且相互独立。

    H stretches 2λ input bits to 4λ. Splitting a uniform 2λ-bit seed produces independent uniform halves.

  2. 假设 A 能区分 H。构造针对 G 的测试 B，收到 3λ 位挑战 t 后独立抽取 λ 位 u，并把 u||t 交给 A。t=G(sR) 时恰是 H 的输出。

    Suppose A distinguishes H. A test B for G receives a 3λ-bit challenge t, samples independent λ-bit u, and runs A on u||t. With t=G(sR), this is exactly the output of H.

  3. t 均匀时两个片段独立且均匀，拼接是均匀 4λ 位串。故两个概率分别对齐，Adv(B,G)=Adv(A,H)。G 安全意味着 H 的优势可忽略。

    For uniform t, the independent uniform pieces concatenate to a uniform 4λ-bit string. The two probabilities match exactly, giving Adv(B,G)=Adv(A,H), negligible by G’s security.

(b)

题意 / Problem in brief

使用题给的两轮 Feistel 输出次序，证明即便两个轮密钥独立，整体也不表现为随机置换。

Use the exam’s output order to show that two Feistel rounds do not look like a random permutation even with independent round keys.

解题步骤 / Derivation

  1. 每半 b 位。题给输出的右半是 v₂=F(k₁,v₁)⊕v₀。把右输入 v₁ 固定、左输入变为 v₀⊕Δ，其中 Δ 非零。两次的轮函数值 F(k₁,v₁) 相同。

    Let a half be b bits. The right output is v₂=F(k₁,v₁)⊕v₀. Hold v₁ fixed and change the left input to v₀⊕Δ for nonzero Δ. The first-round function value is identical.

  2. 两次右输出异或等于 Δ，真实概率 1。第二轮的 k₂ 只出现在另一半，无法改变该等式。

    XOR of the right outputs is Δ with probability 1. The second-round key affects the other half and does not change the equality.

  3. 随机置换的第二个 2b 位结果须不同于第一个，共 2^(2b)−1 种。指定其右半后左半任取，有 2^b 种。该右半不同于第一个的右半，已自动排除了第一个结果。理想概率 2^b/(2^(2b)−1)，优势为 1 减去该值。

    The second image under a random permutation is uniform among 2^(2b)−1 values distinct from the first. A specified right half leaves 2^b left halves, and the nonzero Δ already excludes the first image. The ideal probability is 2^b/(2^(2b)−1) and the gap is one minus that value.

2022–23 Q2(a) 公开掩码抵消后仍是确定性输出 Mask cancellation leaves a deterministic value

IERG4150 · PDF p. 4 · 题意改述 / Paraphrased question

(a)

题意 / Problem in brief

加密发送 (r,z)，其中 z=Fₖ(m)⊕r。推导解密并分析加入随机 r 是否能保证 CPA 安全。

Encryption sends (r,z) where z=Fₖ(m)⊕r. Derive decryption and decide whether this randomness suffices for CPA security.

解题步骤 / Derivation

  1. 先由两个字段算 z⊕r=Fₖ(m)，持钥者再用逆置换得到 Fₖ⁻¹(z⊕r)=m。

    The two fields give z⊕r=Fₖ(m). The key holder then recovers Fₖ⁻¹(z⊕r)=m.

  2. 同一个 m 即使另抽 r，消去 r 后仍是同一个 Fₖ(m)。不同 m 由于置换单射而得到不同的值。例中若 Fₖ(m)=011，用 r=110 产生 z=101，用 r=001 产生 z=010；两组异或都回到 011。

    Fresh r leaves the same publicly determined Fₖ(m) for repeated m. The permutation is injective, so different messages give different values. If Fₖ(m)=011, masks 110 and 001 give z values 101 and 010; both public XORs return 011.

  3. 在 CPA 左右实验里，一个参考加密固定为 m₀，另一个加密左为 m₀、右为不同的 m₁。比较两次的 z⊕r，左边相同的概率 1，右边 0，优势为 1。

    In the CPA game use a fixed reference encryption of m₀ and compare the public invariants for a challenge of m₀ versus distinct m₁. Equality occurs with probability 1 on the left and 0 on the right, a gap of 1.

2023–24 Q2 异或生成器与嵌套 PRF XOR-combined generators and a nested PRF

IERG4150 · PDF p. 8 · 题意改述 / Paraphrased question

(a)

题意 / Problem in brief

G₁、G₂ 均由 λ 位到 3λ 位，H 对独立两半种子输出 G₁(s₁)⊕G₂(s₂)。证明只要其中一个是安全 PRG，H 即安全。

Both G₁ and G₂ map λ bits to 3λ. H XORs their outputs on independent seed halves. Prove security if either component is a secure PRG.

解题步骤 / Derivation

  1. 对称地假设 G₁ 安全。测试收到 t 时独立抽 s₂ 并运行 H 的区分器于 t⊕G₂(s₂)。若 t 是 G₁ 的输出，正好模拟 H。

    By symmetry assume G₁ is secure. A test receiving t independently selects s₂ and runs the H distinguisher on t⊕G₂(s₂). If t comes from G₁ this exactly simulates H.

  2. 若 t 均匀，固定任一 s₂ 后异或常量是双射，所以结果仍均匀；去掉对 s₂ 的条件也均匀。于是两优势完全相等。H 输入 2λ、输出 3λ，所以保留了伸长。

    With uniform t, conditional on any fixed s₂, XOR with the resulting constant is bijective. Removing the conditioning still gives a uniform output. Thus the advantages are equal. H expands 2λ bits to 3λ.

(b)

题意 / Problem in brief

F 输入输出都是 λ 位。判断 F*(r₁||r₂)=Fₖ(Fₖ(r₁)⊕Fₖ(r₂)) 是否仍是 PRF。

F takes and returns λ bits. Analyze whether F*(r₁||r₂)=Fₖ(Fₖ(r₁)⊕Fₖ(r₂)) is a PRF.

解题步骤 / Derivation

  1. 选两个不同的块 x 和 y。用 x||x 与 y||y 两个不同输入，括号里的异或各为全零，所以真实输出都等于 Fₖ(0^λ)。相同事件概率 1。

    Choose distinct blocks x and y. At the distinct inputs x||x and y||y, the inner XOR is all zero in both cases. The real outputs are both Fₖ(0^λ), giving equality with probability 1.

  2. 随机函数对两个不同输入独立抽取 λ 位输出。第一个固定后第二个恰好相等的概率 2^(−λ)。优势 1−2^(−λ)，所以构造不是安全 PRF。

    A random function samples independent λ-bit outputs at two distinct inputs. Conditional on the first, the second matches with probability 2^(−λ). The gap is 1−2^(−λ), so the construction is insecure.

2024–25 Q2(a–b) 逆置换解密与 CCA 分析 Inverse-permutation decryption and CCA

IERG4150 · PDF p. 4 · 题意改述 / Paraphrased question

(a)

题意 / Problem in brief

题意 / Problem in brief

分组密码、模式、IV 和计数器

Block ciphers, modes, IVs and counters

分组密码（block cipher）用密钥 K 把一个固定长度的块变成另一个同长度块，写作 Eₖ，解密写作 Dₖ。工作模式（mode of operation）规定长消息如何分块、每块的输入怎样连接。用 Pᵢ 表示第 i 个明文块、Cᵢ 表示密文块。⊕ 表示逐位异或，可用 (A ⊕ B) ⊕ B = A 消去同一掩码。

A block cipher maps one fixed-size block to another under key K. Write Eₖ for encryption and Dₖ for decryption. A mode of operation determines how a long message is divided and how the block inputs are formed. Pᵢ and Cᵢ denote plaintext and ciphertext blocks. ⊕ is bitwise XOR, so (A ⊕ B) ⊕ B = A cancels a repeated mask.

初始化向量（initialization vector, IV）是某些模式的起始输入，可以随密文传送。Nonce 强调在同一密钥下只使用一次。CBC 和 CFB 要求加密时的 IV 不可预测。OFB 的 IV 要唯一。CTR 要保证同一密钥下的每一个计数器块（counter block）唯一，包括不同消息的块号范围。IV/nonce 与秘密密钥各自承担不同角色。

An initialization vector (IV) is a starting input that may be transmitted with ciphertext. A nonce emphasizes one use per key. CBC and CFB require an unpredictable IV for encryption. OFB requires a unique IV. CTR requires every counter block to be unique under one key, across all messages and their counter ranges. IVs or nonces and secret keys serve distinct roles.

解题步骤 / Derivation

  1. 加密是 Cᵢ=Fₖ(Pᵢ⊕Cᵢ₋₁)。若 Pⱼ 改一位，前 j−1 个输入相同，密文相同。第 j 块的置换输入改变，单射保证 Cⱼ 改变。

  2. 对 j+1 及以后，明文不变而前一个密文值改变。与相同明文异或仍不同，经过置换仍不同，归纳得到 Cⱼ,…,Cℓ 均改变。每块改变的是值，不代表每一位都变。

    For blocks after j, XORing the fixed plaintext with two different preceding ciphertexts gives different inputs. The permutation preserves the inequality. This changes Cⱼ,…,Cℓ as block values; it does not imply every bit changes.

  3. 解密是 Pᵢ=Fₖ⁻¹(Cᵢ)⊕Cᵢ₋₁。Cⱼ 改变使 Pⱼ 经过逆置换得到另一个块，Pⱼ₊₁ 因前一密文改变而同一位翻转，后续两项输入均未受影响。如果 j 是最后一块，只有 Pⱼ 改变。

    Decryption uses Pᵢ=Fₖ⁻¹(Cᵢ)⊕Cᵢ₋₁. A change to Cⱼ changes Pⱼ through the inverse permutation. Pⱼ₊₁ flips the corresponding bit through its outer XOR. Later blocks use two unaffected ciphertext blocks. If j is last, only Pⱼ changes.

题意 / Problem in brief

两次加密都用同一密钥与同一起始 IV。分别说明 CBC 和 CTR 密文泄露的明文关系。

Two encryptions reuse a key and an IV. Characterize the plaintext relations revealed by their CBC ciphertexts and by their CTR ciphertexts.

解题步骤 / Derivation

  1. CBC 第一块 C₁=Fₖ(P₁⊕IV)。由置换一一对应，C₁=C′₁ ⇔ P₁=P′₁。若前一密文也相同，第 i 块同理，所以对应密文的最长公共前缀等于明文的最长公共前缀，以整块计。

    CBC starts with C₁=Fₖ(P₁⊕IV). Injectivity gives C₁=C′₁ ⇔ P₁=P′₁. The same holds at block i if the preceding ciphertexts match. The longest matching ciphertext prefix therefore reveals the longest matching plaintext prefix in whole blocks.

  2. 更一般地，若两个对应 Cᵢ 恰好相等，则 Pᵢ⊕Cᵢ₋₁=P′ᵢ⊕C′ᵢ₋₁，移项得 Pᵢ⊕P′ᵢ=Cᵢ₋₁⊕C′ᵢ₋₁。只有对应密文碰巧等值时才能用这个等式。

    More generally, if corresponding Cᵢ values match, their permutation inputs are equal. Rearranging Pᵢ⊕Cᵢ₋₁=P′ᵢ⊕C′ᵢ₋₁ gives Pᵢ⊕P′ᵢ=Cᵢ₋₁⊕C′ᵢ₋₁. This equality is conditional on a ciphertext match.

  3. CTR 两边相同位置使用同一个 Sᵢ=Fₖ(IV+i−1)。因此重叠范围每块都有 Cᵢ⊕C′ᵢ=(Pᵢ⊕Sᵢ)⊕(P′ᵢ⊕Sᵢ)=Pᵢ⊕P′ᵢ。这暴露逐位关系，包含但远超前缀是否相同的信息。

    CTR reuses an identical Sᵢ=Fₖ(IV+i−1) at each overlapping position. Thus every overlapping block reveals Cᵢ⊕C′ᵢ=(Pᵢ⊕Sᵢ)⊕(P′ᵢ⊕Sᵢ)=Pᵢ⊕P′ᵢ, a bitwise relation beyond just prefix matching.

  1. 令 R 长 t 位，以相同用户名和字段边界比较。固定 IV 后，单块 CBC 仍是对整个输入的固定置换。密文相同当且仅当整个填充后输入相同。

    Let R have t bits and consider equal usernames and field boundaries. With the IV fixed, single-block CBC is a fixed permutation on the whole padded input. Ciphertexts match exactly when these full inputs match.

  2. 如果两次 b 不同，密文相同概率为 0。如果 b 相同，两次的 R 只有恰好相同才匹配，概率为 1/2^t。所以存在可观测差异；判断有多大用处必须知道 t 和比较次数。

    With different b values, matching ciphertexts have probability zero. With equal b values the pads must coincide, with probability 1/2^t. There is an observable distinction whose usefulness depends on t and the number of comparisons.

  3. 若拿一个独立样本与 q 个同标记样本作比较，出现匹配的概率为 1−(1−2^(−t))^q，至多 q/2^t。例如教学值 t=4、q=3 得 1−(15/16)^3=721/4096≈17.60%。理想 PRP 下，随机尾足够长且样本有限时，重复事件可忽略。卷面没有给 t，不能无条件下结论。

    Comparing one independent sample with q samples under the same flag gives match probability 1−(1−2^(−t))^q, at most q/2^t. For illustration t=4 and q=3 give 1−(15/16)^3=721/4096≈17.60%. Under an ideal PRP, collisions are negligible with sufficiently long padding and bounded sampling. The paper leaves t unspecified.

(b)

题意 / Problem in brief

随机 IV 保持原值，只有 Cᵢ 的一位变化。分析解密后的影响。

Keep the random IV unchanged and change one bit of Cᵢ. Identify the affected plaintext blocks.

解题步骤 / Derivation

  1. 第 i 块需要 Fₖ⁻¹(Cᵢ)，所以改变 Cᵢ 使 Pᵢ 的整块取值改变，从题目无法推断具体哪些位变。

    Block i uses Fₖ⁻¹(Cᵢ). Changing Cᵢ changes Pᵢ as a block, with no general prediction of the exact bit pattern.

  2. 第 i+1 块的逆置换输入是 Cᵢ₊₁，保持原值；它最后异或 Cᵢ，因此只变化对应的一位。其他块不使用 Cᵢ，均保持原值。若 Cᵢ 是最后一块，省略 i+1。IV 的随机性不影响这条依赖关系。

    The inverse input Cᵢ₊₁ is unchanged at block i+1, so its final XOR with Cᵢ changes exactly the corresponding bit. Other blocks do not use Cᵢ. Omit i+1 if Cᵢ is last. The random IV does not change these dependencies.

(c-i)

题意 / Problem in brief

按题中伪代码，CBC 的第一块依然依赖随机 c₀，但发送的是 c′₀=Fₖ(c₀)。判断修改后的 CPA 安全性。

    The header and first ciphertext block are Fₖ(c₀) and Fₖ(m₁⊕c₀). Injectivity of the same permutation makes equality equivalent to c₀=m₁⊕c₀, hence m₁=0^λ.

  2. 用全零块和任意非零块作两个等长候选。头部相等事件概率为 1 与 0，区分优势为 1。随机选择 c₀ 对这个等式没有影响。

    Use a zero block and a nonzero block as equal-length candidates. The header-match event has probabilities 1 and 0, so its distinguishing gap is 1 independently of c₀.

(c-ii)

题意 / Problem in brief

仍要求通过 F 得到发送的 IV 字段。给出能保持 CPA 安全的构造和理由。

Keep a transmitted IV field computed with F, but give a construction that retains CPA security.

解题步骤 / Derivation

    Sample separate independent keys kᵢᵥ and kₑ. Use kₑ and random c₀ for ordinary CBC, and transmit h=F(kᵢᵥ,c₀) as the header. The key holder inverts h under kᵢᵥ to get c₀ and performs ordinary CBC decryption.

    Treat it as postprocessing an ordinary CPA-secure CBC ciphertext. A simulator receives (c₀,C₁,…,Cℓ), samples kᵢᵥ, and transforms only the header. A distinguisher for the new scheme yields one for CBC. Independent permutations remove the equality condition of part (c-i).

取模、互质与模逆

Remainders, coprimality and modular inverses

17 mod 5 = 2 表示 17 除以 5 余 2。17 ≡ 2 (mod 5) 表示两数对 5 取余相同。最大公约数（greatest common divisor, gcd）是两个数共同的最大正因子。gcd(e, φ(n)) = 1 表示两者互质（coprime），此时 e 在模 φ(n) 下有模逆（modular inverse）d，满足 ed ≡ 1 (mod φ(n))。

17 mod 5 = 2 means 17 leaves remainder 2 on division by 5. 17 ≡ 2 (mod 5) means both numbers have that same remainder. The greatest common divisor (gcd) is the largest positive divisor shared by two numbers. gcd(e, φ(n)) = 1 means the numbers are coprime, so e has a modular inverse d satisfying ed ≡ 1 (mod φ(n)).

质数 p、q 互异时，欧拉函数（Euler’s totient）φ(pq) = (p−1)(q−1)。它数的是 1 到 n 里与 n 互质的整数。RSA 里 找私钥指数 d 用 φ(n)，处理消息、密文和签名用 n。算大幂先算平方，每一步取余，最后拼出所需指数，这叫平方乘法（square-and-multiply）。

For distinct primes p and q, Euler’s totient is φ(pq) = (p−1)(q−1). It counts integers from 1 through n coprime to n. For RSA, find the private exponent d using φ(n), and compute message, ciphertext and signature powers modulo n. Repeatedly square with reductions and combine the needed powers. This is square-and-multiply.

例题 6 · 生成 RSA 密钥，再加密和解密

Example 6 · Generate RSA keys, encrypt and decrypt

  1. 取 p=5, q=11，所以 n=55，φ(n)=4×10=40。
  2. 选 e=3。因为 40 = 13×3 + 1，两者互质，且 1 = 40−13×3。所以 d ≡ −13 ≡ 27 (mod 40)。验算 3×27=81=2×40+1。公钥是 (55,3)，本题私钥记作 (55,27)。
  3. 加密消息整数 m=12。12² mod 55 = 34，再乘 12 得 408 mod 55 = 23，所以 c=23。
  4. 解密算 23² mod 55 = 34 和 23⁴ mod 55 = 34² mod 55 = 1。因为 27=6×4+2+1，23²⁷ mod 55 = 1⁶×34×23 mod 55 = 12，取回原消息。
  1. Choose p=5, q=11, giving n=55 and φ(n)=4×10=40.
  2. Choose e=3. Since 40 = 13×3 + 1, the gcd is 1 and 1 = 40−13×3. Thus d ≡ −13 ≡ 27 (mod 40). Check 3×27=81=2×40+1. The public key is (55,3). Represent the private key as (55,27) here.
  3. Encrypt message representative m=12. 12² mod 55 = 34. Multiply by 12 and reduce 408 mod 55 = 23, so c=23.
  4. To decrypt, get 23² mod 55 = 34 and 23⁴ mod 55 = 34² mod 55 = 1. Since 27=6×4+2+1, 23²⁷ mod 55 = 1⁶×34×23 mod 55 = 12, recovering the original representative.

为什么能解回来？本题 12 与 55 互质，欧拉定理给出 12⁴⁰ ≡ 1 (mod 55)。因此加密再解密等于 12⁸¹ = 12 × (12⁴⁰)² ≡ 12。若题目要证明对所有消息整数成立，可分别在模 p 和模 q 下处理。

选 e 的条件是互质。例如 e 取 5 时，gcd(5,40)=5，找不到满足条件的 d。

Why does decryption work? Here 12 and 55 are coprime, so Euler’s theorem gives 12⁴⁰ ≡ 1 (mod 55). Encrypting and decrypting gives 12⁸¹ = 12 × (12⁴⁰)² ≡ 12. A proof for all message representatives works separately modulo p and modulo q.

For e the condition is coprimality. If e were 5, gcd(5,40)=5, so a suitable inverse d could not exist.

裸 RSA、OAEP 和数字签名各解决什么

Textbook RSA, OAEP and signatures solve different problems

裸 RSA（textbook RSA）直接计算 c=mᵉ mod n。同一公钥下同一个整数总给同一个密文，这种确定性（determinism）与选择明文安全的目标冲突。RSA-OAEP 在做 RSA 运算前用随机种子和掩码编码消息，使重复加密同一消息通常得到不同密文。

Textbook RSA computes c=mᵉ mod n directly. The same integer and public key always give the same ciphertext. This determinism conflicts with the goal of chosen-plaintext security. RSA-OAEP first encodes the message with a random seed and masks, so encryptions of the same message usually differ.

Hand exercises often provide an encoded representative h and focus on the modular powers.

例题 7 · 生成签名 28，再用公钥验签

Example 7 · Generate signature 28 and verify it with the public key

沿用 n=55, e=3, d=27。题设消息编码代表值 h=7，签名算 s = hᵈ mod 55。依次平方并取模，得 7² → 49、7⁴ → 36、7⁸ → 31、7¹⁶ → 26。

Since 27=16+8+2+1, multiply 26×31×49×7. Reduce after each multiplication to get 36 → 4 → 28, so s=28. Verify by computing 28² mod 55 = 14, then 14×28 mod 55 = 7. It matches the representative for this message, so verification succeeds.

2021–22 Q6 裸 RSA 签名与验签的含义 Textbook RSA signatures and the verification interface

IERG4150 · PDF p. 7 · 题意改述 / Paraphrased question

(a)

题意 / Problem in brief

把消息代表值 y 直接用私钥指数签成 s=y^d mod N。判断它是否满足选择消息下的存在性不可伪造。

Sign a raw message representative y as s=y^d mod N. Assess existential unforgeability under chosen messages.

安全分析 / Security analysis

  1. 正确性来自 (y^d)^e≡y (mod N)。不可伪造性则问：即便可以拿到所选消息的合法签名，是否还能给一个没请求过的消息找到可被接受的签名。两者属于不同要求。

    Correctness is (y^d)^e≡y (mod N). Unforgeability asks whether signatures on chosen messages enable a valid signature on a fresh message. These are different requirements.

  2. 令 V(s)=s^e mod N。整数乘法与求幂满足 V(s₁s₂)=V(s₁)V(s₂) mod N。一次已知签名暴露的是这个可逆代数关系中的一个输入输出对。裸校验接受任意模 N 代表值，没有标准消息编码来消除这些由公钥可检查的结构。故不能满足存在性不可伪造。

    Let V(s)=s^e mod N. Exponentiation preserves multiplication, V(s₁s₂)=V(s₁)V(s₂) mod N. A known signature provides one input/output pair in this invertible relation. Raw verification accepts arbitrary representatives without standard encoding to rule out these public algebraic relationships. The scheme is not existentially unforgeable.

  3. 防护使用标准 RSA-PSS。验证者对消息和签名共同做完整编码检查，裸的模幂等式不足以通过验证。

    Use a standard scheme such as RSA-PSS. Verification checks a structured encoding against the supplied message; the raw modular equation alone no longer suffices.

(b)

题意 / Problem in brief

评论“任何公钥签名的验签都是对签名做公钥加密”是否正确。

Assess the claim that verifying any public-key signature is equivalent to encrypting the signature.

解题步骤 / Derivation

  1. 验签的一般接口是 Verify(pk,m,σ)→accept/reject，输入已经包括消息。裸 RSA 恰好用公开指数求 σ^e mod N，再与题给消息代表值作比较。

    The general interface is Verify(pk,m,σ)→accept/reject, with the message supplied as input. Textbook RSA happens to exponentiate σ with the public exponent and compare the result with the supplied representative.

  2. 公钥加密则把明文编码成收件人能解密的密文。标准 PSS 验签检查编码是否和 m 一致，其他签名也可用群等式而不需要任何加密算法，所以不能推广那个说法。

    Public-key encryption instead produces a ciphertext for the recipient. PSS checks an encoding against m, and other signatures can verify group equations without an encryption algorithm. The claim does not generalize.

2022–23 Q4 确定性加密与验签是否恢复消息 Deterministic encryption and message recovery

IERG4150 · PDF p. 6 · 题意改述 / Paraphrased question

(a)

题意 / Problem in brief

明文代表值直接做 c=m^e mod N。两个候选明文能否在 CPA 实验中区分？

Encrypt the plaintext representative directly as c=m^e mod N. Can two candidate plaintexts be distinguished in the CPA game?

解题步骤 / Derivation

  1. 固定公钥后，每个 m 总对应同一个 c。因为在合法 RSA 参数下这是一一映射，任意两个不同代表值的密文也不同。

    For a fixed public key, each m gives a fixed c. Under valid RSA parameters the map is bijective, so different representatives give different ciphertexts.

  2. 在抽象 CPA 实验里，候选 m₀、m₁ 的公钥计算结果分别记 c₀、c₁。判断挑战输出等于 c₀ 的概率分别是 1、0，优势为 1。数值示意 N=55,e=3 时，7³ 余 13，12³ 余 23，两侧支持集各只有一个且不相交。

    In the abstract CPA experiment, the public images of m₀ and m₁ are c₀ and c₁. A match to c₀ has probabilities 1 and 0, for gap 1. For illustration with N=55,e=3, 7³ reduces to 13 and 12³ to 23, giving disjoint singleton supports.

  3. 所以裸 RSA 不满足选择明文安全。RSA-OAEP 把带随机种子的编码送入 RSA 核心，让同一消息在不同随机选择下对应不同代表值。

    Thus textbook RSA is not CPA-secure. RSA-OAEP feeds a randomized encoding into the RSA primitive, giving distinct representatives for different randomness on the same message.

(b)

题意 / Problem in brief

“验签的一般含义是仅从签名取回被签消息”。判断并解释裸 RSA 的例子。

Assess the claim that verification generally recovers the signed message from the signature alone.

解题步骤 / Derivation

  1. 普通签名方案收 m 和 σ，输出通过或拒绝。裸 RSA 的公开求幂确实给出一个模 N 代表值，但验证仍要比较 σ^e mod N = m。

    Ordinary verification takes m and σ and accepts or rejects. Textbook RSA does produce one representative by public exponentiation, but verification still compares σ^e mod N = m.

  2. 在标准签名里，该计算的结果可只是待检查的编码。例如 RSA-PSS 从另行给定的 m 重新算哈希，与编码内的内容核对；这个接口不承诺从 σ 还原整个文件。

    In standardized signatures the result can be an encoding for validation. RSA-PSS hashes the separately supplied m and checks the encoding against it. The interface does not promise to recover a full file from σ.

签名 σ=m^d mod N，验签把 σ^e mod N 和 m 比较。判断选择消息下的安全。

(b)

题意 / Problem in brief

卷面把目标写成 m′≡(r·m) (mod p)。推导 RSA 的乘法性质，并区分 mod p 与 mod N 的解释。

解题步骤 / Derivation

  1. RSA 运算的模数是 N=pq。定义 T(x)=x^e mod N，则 T(rm mod N)=(rm)^e mod N=(r^e m^e) mod N=T(r)T(m) mod N。这对应模 N 的消息代表值。

    RSA operates modulo N=pq. For T(x)=x^e mod N, T(rm mod N)=(rm)^e mod N=(r^e m^e) mod N=T(r)T(m) mod N. The result is for a representative modulo N.

  2. 该代表值与 rm 在模 p 上也同余，因为 p 整除 N。若原题的 mod p 指取到 0,…,p−1 的标准余数，则两种代表值一般不同。例中 p=5,N=55,r=2,m=6,e=3，rm 的两种余数为 12 和 2，RSA 值分别为 23 和 8。

题意 / Problem in brief

解释不给裸 RSA 的明文做填充或随机编码为何危险。

Explain why using RSA directly on an unencoded message is dangerous.

解题步骤 / Derivation

  1. 固定公钥和 m 时，输出总为同一 c；同一消息的重复能被观察到。小消息与低指数还可能保留整数幂结构，且裸置换保留乘法结构。三个现象都源于直接把 m 当代表值。

(d)

题意 / Problem in brief

说明裸签名在攻击者可请求自己选择的消息签名时，为什么难以保护一个指定的新消息代表值。

    The interface cannot ensure that a fresh representative was encoded from the intended message by the signer. RSA-PSS binds the message digest through structured verification. Correct e selection or hiding the implementation does not fix the raw construction.

群、生成元与 Diffie–Hellman 密钥交换

Groups, generators and Diffie–Hellman key exchange

这里的群（group）是一组可做模乘法的数。结果仍在组内，1 是单位元，每个元素都有乘法逆元。一个循环群（cyclic group）里的元素都可写成某个生成元 g 的幂。g 的阶（order of g）是让 gq ≡ 1 (mod p) 成立的最小正指数 q，所以 g 的幂每 q 步循环一次。

Here a group is a set of numbers closed under modular multiplication, with identity 1 and a multiplicative inverse for every element. In a cyclic group, all elements are powers of a generator g. The order of g is the smallest positive exponent q with gq ≡ 1 (mod p), so its powers cycle every q steps.

Diffie–Hellman（DH）让双方各保留一个秘密指数 a、b，交换公开值 A=gᵃ mod p 和 B=gᵇ mod p。一方算 Bᵃ，另一方算 Aᵇ，都得到 gᵃᵇ。算群元素取模 p，化简 g 的指数可以对 q 取模。使用 DH 建立带身份的连接时，还要认证交换的公钥或握手消息。

In Diffie–Hellman (DH), each side keeps its secret exponent a or b and exchanges a public value A=gᵃ mod p or B=gᵇ mod p. They compute Bᵃ and Aᵇ, respectively, and both get gᵃᵇ. Reduce group values modulo p and exponents of g modulo q. Authenticated key exchange also authenticates the exchanged public values or handshake messages.

ElGamal 怎样把 DH 共享值用来加密

How ElGamal uses a DH shared value for encryption

收件人保有私钥 x，公布 h=gˣ。发送者为每次加密独立选择随机指数 r（ephemeral exponent），得到 c₁=gʳ 和共享掩码 S=hʳ。消息代表值 m 在群内，c₂=m·S。收件人用 c₁ˣ=S 和逆元 S⁻¹ 取回 m=c₂·S⁻¹。这是 DH 的两个临时公开值与共享值关系在加密里的应用，其中收件人的 h 来自固定私钥。

The recipient keeps private x and publishes h=gˣ. The sender independently chooses an ephemeral exponent r for each encryption, producing c₁=gʳ and shared mask S=hʳ. For a message representative m in the group, c₂=m·S. The recipient computes c₁ˣ=S and its inverse S⁻¹ to recover m=c₂·S⁻¹. This uses the DH relation between two public values and a shared value. The recipient’s h comes from the long-term private key.

在满足 DDH 假设的群里，可把 hʳ 与独立随机群元素进行比较。若掩码真的是均匀群元素，那么对任意固定 m，乘以 m 只是把群元素重新排列，所以 m·S 仍均匀。这个推理说明 ElGamal 的 IND-CPA 保密性来自哪里。原始 ElGamal 具有可塑性，完整的 CCA 安全需要使用满足更强定义的构造。

Under the DDH assumption, compare hʳ with an independent random group element. With a uniform mask, multiplication by any fixed m permutes the group, so m·S is still uniform. This explains the source of ElGamal’s IND-CPA confidentiality. Textbook ElGamal is malleable. CCA security requires a construction that meets the stronger definition.

题意 / Problem in brief

ElGamal 的密文为 (g^b,M·A^b)。说明同一个未知群元素 M 为什么可以有不同密文而解密不变。

安全分析 / Security analysis

  1. 设 A=g^a。任何指数 b 的合法密文都会用 (g^b)^a=A^b 消去掩码，得到 M。指数改为 b+t mod n 后，同样有 (g^(b+t))^a=A^(b+t)，两个分量改变中的公共因子在解密时一起抵消。

  2. 这就是重随机化（rerandomization）的代数性质。只要 t 在模 n 下非零，由 g 的阶可知两个 B 不同。讲义的小群例子 p=23、g=2、A=8、M=9 下，合法指数 7 与 4 给出 (13,16) 和 (16,18)，分别消去掩码 12 和 2 都回到 9。

摘要与哈希的三个安全性质

Digests and the three hash security properties

哈希函数（hash function）H 把可变长度的输入映射成固定 n 位的摘要（digest）。同样的输入字节总得到同一个摘要。输入的可能性比摘要多，所以必然存在两个不同输入得到相同摘要。安全性质关心的是，在给定限制下找到它们有多难。

A hash function H maps inputs of varying length to a fixed n-bit digest. Identical input bytes always produce the same digest. There are more possible inputs than digests, so distinct inputs with the same digest must exist. Security is about how hard it is to find them under the stated constraints.

Example 11 · Does repeating a digest increase collision resistance?

|| 表示按顺序拼接（concatenation）。设 J(x)=H(x)||H(x)。如果 H 给出三位摘要 101，J 输出 101101。虽然有六个位，后半完全由前半决定，因此最多 2³=8 种可能输出。一般情形下，J(x)=J(x′) 恰好当 H(x)=H(x′)。

|| denotes ordered concatenation. Let J(x)=H(x)||H(x). A three-bit H digest 101 yields 101101 under J. The output has six bits but the first half determines the second, leaving at most 2³=8 possibilities. In general, J(x)=J(x′) holds exactly when H(x)=H(x′).

所以 J 的碰撞还是 H 的同一对碰撞。构造题还要区分编码与哈希。把字段 (AB,C) 和 (A,BC) 直接拼接，两组都得到字节串 ABC，哈希接到的输入已经一样。带长度的编码能让两组字段对应不同字节串，然后才能讨论真正的哈希碰撞。

A collision for J is the same pair as a collision for H. In construction questions, separate encoding from hashing. Concatenating the fields (AB,C) and (A,BC) directly gives ABC in each case. The hash sees identical input bytes. A length-aware encoding makes the byte strings distinct so the hash collision question is well defined.

例题 12 · 8 位摘要做 20 次，至少一次碰撞的概率

Example 12 · Probability of a collision in 20 trials with an 8-bit digest

生日问题（birthday problem）问的是任意一对是否相同。把每次新输入的摘要当作独立均匀抽样，N=2⁸=256。第一次不会撞到之前的值，第二次要避开 1 个值，第三次要避开 2 个，以此类推。恰好比较了 20×19/2=190 对候选。

The birthday problem asks whether any pair matches. Model each digest of a new input as an independent uniform draw from N=2⁸=256 values. The first draw has nothing to match, the second avoids one previous value, the third avoids two, and so on. There are 20×19/2=190 candidate pairs.

  1. 先算全不同 Pr[无碰撞] = 1×(255/256)×(254/256)×…×(237/256)。
  2. 取补集。Pr[至少一次碰撞] = 1 − Pr[无碰撞] ≈ 53.32%。
  3. 手算近似使用 1 − exp(−k(k−1)/(2N))，代入 N=256、k=20 得 52.39%。约 50% 的阈值是 k ≈ √(2N ln 2) ≈ 1.177√N，这里约 19 次。
  4. 若每次只匹配一个给定的目标摘要，用 1−(255/256)²⁰ ≈ 7.53%。这是固定目标与任意一对两个不同事件。
  1. Start with all distinct, Pr[no collision] = 1×(255/256)×(254/256)×…×(237/256).
  2. Take the complement, Pr[at least one collision] = 1 − Pr[no collision] ≈ 53.32%.
  3. Use the hand approximation 1 − exp(−k(k−1)/(2N)). Substituting N=256 and k=20 gives 52.39%. The approximate 50% threshold is k ≈ √(2N ln 2) ≈ 1.177√N, about 19 draws here.
  4. For matching a single fixed target, use 1−(255/256)²⁰ ≈ 7.53%. A fixed target and any matching pair are different events.

(a)

题意 / Problem in brief

设 H(x||y)=F(x,y)，F 固定 x 时是可逆置换。给定 x||y，问能否找到另一输入使摘要相同。

Let H(x||y)=F(x,y) with a permutation keyed by x. Given x||y, find whether another input can have the same digest.

解题步骤 / Derivation

  1. 先记目标 z=F(x,y)，再取不同的密钥字段 x′。因为这个“密钥”只是公开哈希输入的一段，可以计算 y′=F⁻¹(x′,z)。

    Compute z=F(x,y) and choose a different key field x′. This “key” is supplied as a public hash input, so evaluate y′=F⁻¹(x′,z).

  2. 两串的 x 字段不同，所以必为不同输入。代入 H(x′||y′)=F(x′,F⁻¹(x′,z))=z，得到第二原像，当然也得到碰撞。

    The x fields differ, so the full inputs are distinct. Substitution gives H(x′||y′)=F(x′,F⁻¹(x′,z))=z, a second preimage and thus also a collision.

  3. 小例中假设两个公开置换分别对 16 取余加 3、加 5。第一个把 6 映成 9，第二个令 y′=9−5=4 也映成 9。固定一个 x 时置换没有碰撞，跨两个 x 的组合才是题目的哈希输入域。

    As a small example, two public permutations add 3 or 5 modulo 16. The first maps 6 to 9; the second maps 9−5=4 to 9. One fixed permutation is injective, but the hash domain includes the key field too.

(b)

题意 / Problem in brief

H 本来抗碰撞。定义 H′(x)=H(x)⊕H(x⊕1^|x|)。判断是否保留抗碰撞性。

H is collision resistant. Decide whether H′(x)=H(x)⊕H(x⊕1^|x|) preserves that property.

解题步骤 / Derivation

  1. 令 x̄ 为非空串 x 的补码。补码做两次回到 x，所以 H′(x)=H(x)⊕H(x̄)，而 H′(x̄)=H(x̄)⊕H(x)。

    Let x̄ be the complement of a nonempty x. Complementing twice recovers x, giving H′(x)=H(x)⊕H(x̄) and H′(x̄)=H(x̄)⊕H(x).

  2. 异或可交换，因此输出相同，输入却不同。取 x=011，则 x̄=100；哪怕底层 H 在这两个输入上给不同摘要，外层也把同一对摘要交换后再异或。H′ 不是抗碰撞函数。

    XOR commutes, giving identical outputs for distinct inputs. With x=011 and x̄=100, the outer XOR just reverses the two digest operands even when the digests themselves are distinct. H′ is not collision resistant.

2024–25 Q3 恒等、截断、异或构造与公开盐 Identity, truncation, XOR and public salt

(a)

题意 / Problem in brief

H 在 n 位输入上直接返回 x，自然没有不同输入的碰撞。评价这个设计。

H returns its n-bit input unchanged, so two distinct inputs never collide. Evaluate the design.

解题步骤 / Derivation

  1. 若 H(x)=H(y)，恒等定义直接得到 x=y。所以在这个固定长度域内，碰撞事件确实不存在。

    With H(x)=H(y), the identity definition gives x=y. There are indeed no collisions on this fixed-length domain.

  2. 但给定任意摘要 z，原像可立即取 x=z。同时输入 n 位、输出 n 位不压缩长数据，也不隐藏任何内容。“没有碰撞”仅说明这一项性质，无法满足通常的密码学摘要用途。

    Given any digest z, its preimage is immediately x=z. It neither compresses longer data nor hides any input. Absence of collisions is only one property and does not make this a useful cryptographic digest.

(b)

题意 / Problem in brief

把长于 n 位的二进制整数取模 H′(x)=x mod 2^n。判断抗碰撞性。

Reduce a binary integer wider than n bits via H′(x)=x mod 2^n. Decide collision resistance.

解题步骤 / Derivation

  1. 用除法写 x=q·2^n+r，0≤r<2^n。摘要只取最低 n 位 r，更高位都被舍弃。

    Write x=q·2^n+r with 0≤r<2^n. The digest retains only the low n bits r and discards the high bits.

  2. 取相同低 n 位，改变一个被舍弃的高位。例中 n=3，0011₂=3 与 1011₂=11，分别除以 8 余 3 和 3。输入不同而摘要相同，因此不抗碰撞。

    Keep the same low n bits and change a discarded high bit. For n=3, 0011₂=3 and 1011₂=11 both have remainder 3 modulo 8. This gives a collision.

(c)

题意 / Problem in brief

H*(x||y) 先算 z=H(x)⊕y，再返回 H(z)⊕x。给定原输入，推导第二原像。

H*(x||y) first computes z=H(x)⊕y and returns H(z)⊕x. Derive a second preimage for a given input.

解题步骤 / Derivation

  1. 由原输入算出 z 和目标摘要 t=H(z)⊕x。另选任意 z′≠z，先从外层反推 x′=t⊕H(z′)。

    Compute z and target digest t=H(z)⊕x from the given input. Choose z′≠z, and work backward through the outer XOR to set x′=t⊕H(z′).

  2. 再从内层反推 y′=z′⊕H(x′)。验证 H(x′)⊕y′=z′，继而 H(z′)⊕x′=t。如果新旧输入相同，算出的内部值也应相同，和 z′≠z 矛盾。

    Work backward through the inner XOR to set y′=z′⊕H(x′). Verify H(x′)⊕y′=z′ and H(z′)⊕x′=t. Identical full inputs would have the same internal value, contradicting z′≠z.

  3. 给定三位的示意哈希值 H(001)=101,H(111)=100,H(011)=110。原输入 001||010 给 z=111,t=101。选 z′=011，得到 x′=101⊕110=011、y′=011⊕110=101。新输入 011||101 算得 z′=011、t′=101。

    Use illustrative three-bit values H(001)=101,H(111)=100,H(011)=110. Input 001||010 gives z=111,t=101. Choose z′=011, yielding x′=101⊕110=011 and y′=011⊕110=101. Input 011||101 gives z′=011 and digest t′=101.

(d)

题意 / Problem in brief

三分组 CBC 链的最后一块作摘要，题设把 k 当公开盐。解释为什么能找到碰撞。

The digest is the final state of a three-block CBC chain with public salt k as the permutation key. Explain how collisions arise.

解题步骤 / Derivation

  1. 对原串求 c₁=Fₖ(m₁)、c₂=Fₖ(m₂⊕c₁)。由于 k 公开，换成不同的 m₁′ 并保持 m₂ 后，也能计算相应状态 c₂′。

    Compute the original states c₁=Fₖ(m₁) and c₂=Fₖ(m₂⊕c₁). Since k is public, also compute c₂′ after changing m₁ and holding m₂ fixed.

  2. 最后一轮只看 m₃⊕c₂。令 m₃′=m₃⊕c₂⊕c₂′ 后，新输入的末轮值 m₃′⊕c₂′=m₃⊕c₂，摘要相同。m₁′ 不同保证整串不同。

    Only m₃⊕c₂ enters the final permutation. Taking m₃′=m₃⊕c₂⊕c₂′ makes m₃′⊕c₂′=m₃⊕c₂, so the digests match. The changed first block makes the full inputs distinct.

  3. 以十六进制玩具置换 F(x)=(x+3) mod 16 验算。 (1,2,3) 得 c₁=4、c₂=9，末轮输入 A、摘要 D。换首块为 0，c₁′=3、c₂′=4，取 m₃′=3⊕9⊕4=E，末轮输入 E⊕4=A，摘要仍 D。

    Check with toy permutation F(x)=(x+3) mod 16 in hex. Input (1,2,3) gives c₁=4 and c₂=9, so the last input is A and the digest D. With first block 0, c₁′=3 and c₂′=4. Then m₃′=3⊕9⊕4=E and E⊕4=A, again giving D.

(a)

题意 / Problem in brief

F 是 PRP。解释把密钥 x 当作普通输入半块时，为何 H(x||y)=F(x,y) 不是抗碰撞哈希。

Explain why H(x||y)=F(x,y) lacks collision resistance when the PRP key x is part of the hash input.

解题步骤 / Derivation

  1. 任选一个输出 z 和两个不同 x 值 x₀、x₁。对每个固定密钥，置换都覆盖整个输出空间，故两个逆像 yᵢ=F⁻¹(xᵢ,z) 都存在且可计算。

    Choose any output z and two keys x₀, x₁. Each permutation covers its entire output set, so both inverse images yᵢ=F⁻¹(xᵢ,z) exist and can be evaluated.

  2. 两个输入 x₀||y₀ 与 x₁||y₁ 因前半不同而不同。各自代入都得 z。与 2023–24 Q3(a) 同理，这一小问允许先自由选目标，而前卷给定一个原输入。

(b)

题意 / Problem in brief

H 连续做固定 t 次得到 H^(t)。已知迭代版本的一对碰撞，怎样定位底层 H 的碰撞？

Let H^(t) apply H t times. Given a collision for the iterate, locate a collision for H itself.

解题步骤 / Derivation

  1. 从不同起点 x 和 y 开始令 x₀=x,y₀=y，逐轮记录 xᵢ=H(xᵢ₋₁), yᵢ=H(yᵢ₋₁)。末轮 xₜ=yₜ。

    Start from distinct x₀=x,y₀=y and record xᵢ=H(xᵢ₋₁), yᵢ=H(yᵢ₋₁). The final round has xₜ=yₜ.

  2. 取第一次相等的 i。此时上一轮必不等，但这两个不同值经 H 都到同一个结果。所以 (xᵢ₋₁,yᵢ₋₁) 是底层碰撞。至多算 2t 次 H。

    Take the first round i at which the values match. The previous values differ and H maps both to the same result, so (xᵢ₋₁,yᵢ₋₁) is a collision for H. At most 2t evaluations are needed.

  3. 例如两条示意链为 001→010→111→000 与 100→011→111→000。首次合并是第二轮，答案取 010、011；末尾的 000 只是已经合并后的共同结果。

    For example, the illustrative chains 001→010→111→000 and 100→011→111→000 first merge at round two. Take 010 and 011. The final 000 is only a common value after that merge.

(c)

题意 / Problem in brief

给定 x||y，先算 z=H(x)⊕y，再输出 H(z)⊕H(y)。定义并推导第二原像。

Given x||y, this construction sets z=H(x)⊕y and outputs H(z)⊕H(y). Define and derive a second preimage.

解题步骤 / Derivation

  1. 第二原像是给定一条输入后，再找一条不同输入使摘要相同。固定 x，把另一半改为 y′=z。新内部值 z′=H(x)⊕y′=H(x)⊕H(x)⊕y=y。

    A second preimage is another input with the same digest as a given input. Hold x fixed and set y′=z. The new internal value is z′=H(x)⊕y′=H(x)⊕H(x)⊕y=y.

  2. 新摘要为 H(y)⊕H(z)，交换顺序与原摘要相等。若 H(x)≠0^n，则 z≠y，两条输入不同。例如 H(x)=101、y=011 得 z=110，选 y′=110 后新内部值回到 011。

    The new digest H(y)⊕H(z) equals the original by commutativity. If H(x)≠0^n, then z≠y and the inputs differ. For H(x)=101 and y=011, z=110; taking y′=110 gives a new internal value 011.

  3. 单独处理 H(x)=0^n。此时对所有 y 都有 z=y，摘要恒为 H(y)⊕H(y)=0^n。任选不同 y′ 即可。这补足了“直接交换时新输入和旧输入相同”的边界情形。

    Handle H(x)=0^n separately. Now z=y for every y, giving a constant digest H(y)⊕H(y)=0^n. Any different y′ is a second preimage. This handles the case where simply swapping leaves the input unchanged.

MAC 的标签验证什么

What a MAC verifies

消息认证码（message authentication code, MAC）用双方共享的秘密密钥 K，计算消息 M 的短标签（tag）T = MACₖ(M)。接收者运行验证算法，确定标签与收到的字节串在同一密钥下匹配。普通哈希只需知道消息即可计算，MAC 的安全性来自秘密密钥。MAC 验证完整性和持钥方认证，消息内容需要用加密保护。

A message authentication code (MAC) uses a shared secret key K to compute a short tag T = MACₖ(M) on message M. The receiver verifies that the tag matches the received bytes under the same key. An ordinary hash needs only the message, while MAC security relies on a shared secret. A MAC checks integrity and authenticates a holder of the key. Encryption protects the message content.

不可伪造性（unforgeability）的考试模型允许观察者取得自己选的消息的标签，要求它仍无法为新的消息生成一个有效标签。理想 t 位标签的一次独立猜中概率是 2⁻ᵗ，例如 t=16 时是 1/65536 ≈ 0.00153%。真实构造还需要分析算法本身、标签长度和使用条件。

In the exam model of unforgeability, an observer can obtain tags on messages it chooses and should still be unable to produce a valid tag for a new message. An independent guess for an ideal t-bit tag succeeds with probability 2⁻ᵗ. At t=16 this is 1/65536 ≈ 0.00153%. Real schemes also depend on the algorithm, tag length, and conditions of use.

例题 13 · 手算两块 CBC-MAC，并交换块的顺序

Example 13 · Calculate a two-block CBC-MAC and swap the blocks

CBC-MAC 从全零状态 X₀=0 开始，用 Xᵢ=Eₖ(Xᵢ₋₁ ⊕ Mᵢ) 连续处理每块，只取最后的 Xₙ 为标签。基本构造的安全条件之一是同一密钥下认证固定长度的消息。需要处理可变长度时，可选适用于该用途的标准构造，例如 CMAC。

CBC-MAC starts from the zero state X₀=0, processes each block with Xᵢ=Eₖ(Xᵢ₋₁ ⊕ Mᵢ), and returns only the last state Xₙ as the tag. The basic scheme’s security uses a fixed message length under the key. For variable-length messages, use a scheme designed for that purpose, such as CMAC.

沿用例题 3 的四位 E(x)=(x+3) mod 16。对两块 (6,A)，X₁=E(0 ⊕ 6)=9，X₂=E(9 ⊕ A)=E(3)=6，标签为 6。改顺序为 (A,6)，X₁=E(A)=D，X₂=E(D ⊕ 6)=E(B)=E（最后的 E 是十六进制 14），标签变为 E。

Reuse the four-bit E(x)=(x+3) mod 16 from Example 3. For (6,A), X₁=E(0 ⊕ 6)=9 and X₂=E(9 ⊕ A)=E(3)=6, yielding tag 6. Swap to (A,6). Now X₁=E(A)=D and X₂=E(D ⊕ 6)=E(B)=E (the final E is hex 14), yielding tag E.

验证端按收到的块和顺序重算，本题的 (A,6) 配标签 6 就不会通过。分析任意设计时，明确序列化如何绑定字段边界、顺序和长度。前一节的 (AB,C) 与 (A,BC) 问题也适用于待认证字段。

The verifier recomputes over the received blocks in order, so (A,6) with tag 6 does not pass this example. For any design, say how serialization binds field boundaries, order and length. The (AB,C) versus (A,BC) encoding issue also applies to authenticated fields.

HMAC 的两层哈希

The two hash layers in HMAC

HMAC（hash-based message authentication code）先使密钥变成哈希压缩函数的块长 B。超过 B 的密钥先哈希，较短的在右侧补零，得到 K₀。HMAC-SHA-256 的 B 是 64 字节，内层摘要是 32 字节。ipad 和 opad 分别是重复 B 次的字节 0x36 和 0x5c。

HMAC (hash-based message authentication code) normalizes the key to the hash block length B. Hash a key longer than B, and right-pad a shorter key with zeros to make K₀. HMAC-SHA-256 uses B = 64 bytes and a 32-byte inner digest. ipad and opad repeat bytes 0x36 and 0x5c, respectively, B times.

先算内层 I = H((K₀ ⊕ ipad) || M)，再算外层 T = H((K₀ ⊕ opad) || I)。外层处理的是内层摘要原始字节，计算题用十六进制显示这些字节。把十六进制字符本身当输入会改变结果。

First compute the inner digest I = H((K₀ ⊕ ipad) || M), then the outer digest T = H((K₀ ⊕ opad) || I). The outer layer receives the raw inner digest bytes. Exercises display these in hexadecimal. Using the hexadecimal characters as input would change the result.

例题 14 · 把一个字节的密钥带入 HMAC-SHA-256

  1. 取教学用密钥 0B、消息 Hi（字节 48 69）。K₀ 是 0B 后补 63 个 00。
  2. 首字节分别算 0B ⊕ 36 = 3D 和 0B ⊕ 5C = 57。因为后 63 个密钥字节都是零，内层前缀为 3D 加 63 个 36，外层前缀为 57 加 63 个 5C。
  3. 内层送入 64+2=66 字节，计算得到 748201ac 83368a34 706a9aa9 8e6525f9 3873f813 ce64b992 d1ebc58b 510316cf。
  4. 外层送入 64+32=96 字节，标签为 b20ac93d 3ed95fc9 652eeb4a 15c868e0 910f75a3 b47836d4 b7aa3e17 b40db3ab。空格仅用于分组阅读。

GCM 的计数器、GHASH 和长度块

GCM counters, GHASH and the length block

GCM（Galois/Counter Mode）用计数器模式加密明文，用 GHASH 累积关联数据 A 和密文 C，再用一个 AES 输出掩盖哈希结果形成标签。对 96 位 IV，初始块 J₀=IV || 0³¹ || 1。Eₖ(J₀) 给标签使用，第一个加密掩码从 inc32(J₀) 开始，其中 inc32 递增末尾 32 位。H=Eₖ(0¹²⁸) 是 GHASH 的子密钥。

GCM (Galois/Counter Mode) encrypts with counter mode, folds associated data A and ciphertext C into GHASH, then masks the result with another AES output to form the tag. For a 96-bit IV, the initial block is J₀=IV || 0³¹ || 1. Eₖ(J₀) masks the tag. The first encryption mask uses inc32(J₀), which increments the low 32 bits. The GHASH subkey is H=Eₖ(0¹²⁸).

GHASH 的输入依次是补齐到整块的 A、补齐的 C、一个长度块。长度块把 A 和 C 补齐前的位数分别编码成 64 位后拼起来。令这些输入块为 Xᵢ，从 Y₀=0 开始算 Yᵢ=(Yᵢ₋₁ ⊕ Xᵢ)·H。点乘在有限域 GF(2¹²⁸) 中做，先按二元多项式相乘，再按 x¹²⁸+x⁷+x²+x+1 约简。标签取 Eₖ(J₀) ⊕ Y_final 的最高 t 位。标签核对失败时应拒绝消息，同一密钥下每条消息的 IV 要唯一。

GHASH processes block-padded A, block-padded C, and a length block. The length block concatenates the original bit lengths of A and C as two 64-bit integers. For those blocks Xᵢ, start with Y₀=0 and compute Yᵢ=(Yᵢ₋₁ ⊕ Xᵢ)·H. Multiply in GF(2¹²⁸), using binary polynomials reduced by x¹²⁸+x⁷+x²+x+1. The tag is the most significant t bits of Eₖ(J₀) ⊕ Y_final. A failed tag check means reject. Each message needs a unique IV under the key.

2021–22 Q5 异或汇总标签与并行认证明文 XOR-folded tags and plaintext tags sent alongside encryption

IERG4150 · PDF p. 6 · 题意改述 / Paraphrased question

(a)

题意 / Problem in brief

把所有 λ 位块先异或成一个值，再对这个值调用 PRF 生成标签。分析 MAC 安全实验中的概率差。

XOR all λ-bit message blocks first and apply a PRF to the result. Analyze the probability gap in the MAC security experiment.

安全分析 / Security analysis

  1. 消息结构在进 PRF 前就丢失了。例如两个不同块 x、y 的有序对在两个次序下都有聚合值 x⊕y=y⊕x，因此最终标签必相同。另一个例子是加入两个相同块会使其 XOR 抵消。

    Structure is lost before the PRF. The two orders of distinct blocks x and y give x⊕y=y⊕x, hence the same real tag. A repeated pair of identical blocks also cancels in the fold.

  2. 区分 MAC 实验时，理想库保留的是已签发的完整“消息、标签”对。对聚合相同而记录不同的两条消息，真实验证因为标签相同可接受同一标签，理想验证对未记录的那条拒绝。该接受事件在两侧是 1 和 0，优势 1。单看标签相同并不能区分这两个库，因为理想库在生成标签时仍调用原 MAC。

    The ideal MAC library records complete issued message/tag pairs. For distinct records with the same aggregate, real verification recognizes a shared tag, while ideal verification rejects the unissued pair. The acceptance gap is 1 versus 0. Mere tag equality does not distinguish these libraries because the ideal library still computes the original MAC when issuing tags.

  3. 缺陷在按位归并，没有绑定顺序和边界。应在无歧义编码后对有序消息使用标准 HMAC 或 CMAC。

    The fold fails to bind the ordered encoding. Authenticate the unambiguous ordered message with a standard construction such as HMAC or CMAC.

(b)

题意 / Problem in brief

E 具 CPA 保密性，M 是安全 MAC。发送 (Enc(kₑ,m), MAC(kₘ,m))，为什么不能据此得到 CCA 安全？

Given a CPA-secure E and a secure MAC M, explain why sending (Enc(kₑ,m), MAC(kₘ,m)) does not ensure CCA security.

解题步骤 / Derivation

  1. 密文有随机性，但附带的明文标签在题设确定性 MAC 下会稳定重现。同一消息的标签匹配概率为 1。对两个固定不同消息，记碰撞概率为 α=Prₖ(MAC(k,m₀)=MAC(k,m₁))。

    The encryption can be randomized but the attached tag on the plaintext is stable under the paper’s deterministic MAC. Repeated messages have matching tags with probability 1. Let α=Prₖ(MAC(k,m₀)=MAC(k,m₁)) for two fixed distinct messages.

  2. 安全 MAC 下 α 必须可忽略，否则不同消息经常会接受同一个标签。在保密实验里，标签的相等事件两侧相差 1−α，已经在 CPA 下泄露消息选择，所以也不满足 CCA。

    For a secure MAC α is negligible, since otherwise a tag would transfer across these fixed messages too often. In the confidentiality game, the tag-match event differs by 1−α. Leakage already occurs under CPA, so CCA fails.

2022–23 Q3 分块标签异或与重复标签的证明 XOR of block tags and the proof for duplicating a tag

IERG4150 · PDF p. 5 · 题意改述 / Paraphrased question

(a)

题意 / Problem in brief

对每块先独立算 Fₖ(mᵢ)，最后把所有输出异或成标签。问这个设计是否正确绑定完整消息。

The tag XORs the per-block values Fₖ(mᵢ). Determine whether it binds the complete message.

安全分析 / Security analysis

  1. 以两个不同块 x、y 为例，内部值为 A=Fₖ(x),B=Fₖ(y)。两种次序的标签分别是 A⊕B 和 B⊕A，由交换律得到相同的 λ 位串，和 F 是否安全无关。

    For distinct blocks x and y let A=Fₖ(x),B=Fₖ(y). Their two orders yield A⊕B and B⊕A, identical by commutativity even if F itself is secure.

  2. 例如示意块标签为 011 和 101，两个方向都得 110。真实验证把不同的有序消息当成同一个标签等价类，违背未签发消息应被拒绝的目标。保护方式是在标准 MAC 输入里保持字段顺序和位置。

    For illustrative block values 011 and 101, both orders give 110. Real verification treats distinct ordered messages as one tag-equivalence class, contrary to the goal for unissued messages. Use a standard MAC over an ordered encoding.

(b)

题意 / Problem in brief

已知 MAC 安全，定义 MAC′(k,m)=t||t，其中 t=MAC(k,m)。证明 MAC′ 也安全。

Given a secure MAC, let MAC′(k,m)=t||t with t=MAC(k,m). Prove MAC′ remains secure.

解题步骤 / Derivation

  1. 模拟生成标签时，只问底层一次 GETTAG(m)，对返回的 t 复制成 t||t。模拟验证时切成两半；两半不同则直接拒绝，两半相同就用其中一半调用底层检查。

    To simulate tag generation, call the base GETTAG(m) once and return t||t. For verification, split the tag, reject unequal halves immediately, and send a common half to the base checker.

  2. 底层真实检查时，M′ 恰好按重复标签定义接受。底层理想检查时，仅已记录的 (m,t) 被接受，等价于外层已记录 (m,t||t)。因此两边模拟都精确，优势相等，底层安全推出上层安全。

    With a real base checker the wrapper exactly implements verification for MAC′. With the ideal base checker it accepts only recorded (m,t), equivalent to recorded (m,t||t) above. The simulations and advantages match exactly, so base security implies wrapper security.

  3. 标签字节数翻倍，但只有前半独立，无法据此声称猜测难度也平方提升。

    The byte length doubles, but only one half is independent; the duplication alone does not square the guessing difficulty.

2024–25 Q2(c–d) 把标签绑定到明文或密文 Tagging plaintext versus ciphertext

IERG4150 · PDF p. 4 · 题意改述 / Paraphrased question

(c)

题意 / Problem in brief

对上一构造附加 t=Fₖ(m)，发送 (c₁,c₂,t)。它是否获得 CCA 安全？

Append t=Fₖ(m) to the previous scheme and send (c₁,c₂,t). Does this give CCA security?

解题步骤 / Derivation

  1. t 公开且固定密钥下只取决于 m。由于 F 是置换，同一 m 的 t 相同，不同 m 的 t 保证不同。即使 c₁、c₂ 因 r 随机变化也不影响这个可观察量。

    The public t depends only on m under a fixed key. Since F is a permutation, equal messages give identical tags and distinct messages give distinct tags, regardless of random changes in c₁ and c₂.

  2. CPA 左右实验中，一次固定 m₀ 作参照，再比较候选 m₀ 或不同 m₁ 的标签。匹配事件在两侧概率分别为 1 和 0，优势 1。并且代入 c₂=r⊕t 可见这个字段组合把内部掩码也变成公开可确定量。

    Compare a fixed reference for m₀ with a challenge for m₀ or distinct m₁ in the CPA game. Tag equality has probabilities 1 and 0, gap 1. The equation c₂=r⊕t additionally makes the internal mask publicly determined.

  3. 方案已不满足 CPA，所以不满足更强的 CCA。标签保护对象和数据流是判断依据，密文多一个字段不自动增加保密性。

    It already fails CPA, hence also CCA. The authenticated data and the information exposed by the fields determine the result.

(d)

题意 / Problem in brief

把标签改成 Fₖ(c₁||c₂)。解释在什么条件下这种思路有望实现 CCA。

Change the tag to Fₖ(c₁||c₂). Explain the conditions under which this approach can give CCA security.

解题步骤 / Derivation

  1. 卷首的 F 只收 λ 位块，而 c₁||c₂ 是 2λ 位。按原公式不能直接调用。此外同一 k 跨加密和认证复用，不符合标准组合定理的独立密钥条件。

    The F declared at the top takes λ bits, whereas c₁||c₂ has 2λ bits. The literal call is not defined. Reusing k across encryption and authentication also fails the separate-key hypothesis of the generic composition theorem.

  2. 修正为对完整的编码密文及必要上下文，用独立密钥调用适当输入域的标准 MAC。接收端先验标签，合法才使用解密结果。认证要覆盖两个字段和顺序，不能只覆盖 c₂。

    Use a standard MAC with the correct input domain and a separate key to authenticate the encoded ciphertext and its context. Verify first and release plaintext only on success. Both fields and their order must be covered.

  3. 这是 Encrypt-then-MAC。标准结论依赖底层 CPA 保密性和认证的不可伪造性，例如确定性唯一标签的安全 MAC。有效的新密文必须有对应标签，原 CCA 实验的相关密文不再能只靠格式通过。直接套题面的公式不能宣称 CCA 已实现。

    This is Encrypt-then-MAC. The standard result requires CPA security of the base and MAC unforgeability, for example a secure deterministic unique-tag MAC. Fresh valid ciphertexts need authentic tags. The literal formula in the question alone does not establish CCA security.
