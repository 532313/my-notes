流密码与随机数

Stream ciphers and random numbers

流密码用异或将消息和一段密钥流合在一起。难点是如何让密钥流难以预测，以及如何确保同一段掩码只使用一次。先看理想的随机密钥，再看怎样从短种子生成长序列。

A stream cipher combines a message and a keystream using XOR. The challenging parts are making the keystream unpredictable and using each piece as a mask only once. Start with an ideal random key, then see how to expand a short seed.

一次一密与完美保密

One-time pad and perfect secrecy

按位异或（Bitwise XOR） 相同的位得到 0，不同的位得到 1。同一个数异或两次会消掉。若 M=1011、K=0110，加密得到 C=1101，解密再算 1101 ⊕ 0110 = 1011。

Bitwise XOR gives 0 for equal bits and 1 for unequal bits. XORing with the same value twice cancels it. With M=1011 and K=0110, encryption gives C=1101. Decryption computes 1101 ⊕ 0110 = 1011.

一次一密（One-Time Pad, OTP） 要求 K 与消息等长、均匀随机、独立并且只用一次。固定任意 n 位明文 m 和密文 c，能使 m ⊕ K = c 的密钥恰好有一个，即 m ⊕ c。每个密钥出现的概率都是 1/2ⁿ，所以换一份等长明文，看到 c 的概率仍相同。这就是 完美保密（Perfect Secrecy） 的直觉。

A one-time pad (OTP) needs a uniform, independent key as long as the message, used only once. For a fixed n-bit message m and ciphertext c, exactly one key satisfies m ⊕ K = c, namely m ⊕ c. Each key has probability 1/2ⁿ. Replacing m with any other n-bit message leaves the probability of seeing c unchanged. This is the intuition for perfect secrecy.

如果两条候选消息的长度分别为 4 字节和 8 字节，密文长度就可能暴露是哪条。安全实验经常要求候选消息等长。一次一密还有长随机密钥的分发和存储成本。

If two candidate messages are four and eight bytes long, the ciphertext length may identify the candidate. Security experiments often require equal lengths. One-time pads also incur the cost of distributing and storing long random keys.

复用例。若 C₁=M₁⊕K 且 C₂=M₂⊕K，则 C₁⊕C₂=M₁⊕M₂。同一密钥流抵消，即使不知道 K，也知道了明文之间的关系。

Reuse example. If C₁=M₁⊕K and C₂=M₂⊕K, then C₁⊕C₂=M₁⊕M₂. The shared mask cancels, exposing a relationship between the plaintexts while K remains unknown.

伪随机生成器（Pseudorandom Generator, PRG） 把短的均匀 种子（Seed） K 扩展为长串 G(K)。同一个种子会产生同样的输出。区分器（Distinguisher） 在两个实验里收到等长的串，一种来自 G，另一种是均匀随机串，然后输出 0 或 1。

A pseudorandom generator (PRG) expands a short uniform seed K into a longer string G(K). The same seed gives the same output. A distinguisher receives equal-length strings in two experiments, one from G and one uniform, then outputs a bit.

优势（Advantage） = | 生成器实验输出 1 的概率 − 均匀实验输出 1 的概率 |。

Advantage = | probability of output 1 for the generator − probability of output 1 for the uniform experiment |.

算例。若生成器输出首位为 1 的概率是 0.51，均匀串为 0.50，检查首位的优势就是 0.01。要求对所有高效区分器的优势可忽略，单凭一组输出看起来杂乱不足以成立。

Worked example. Suppose the first bit is 1 with probability 0.51 for G and 0.50 for the uniform string. Testing that bit gives advantage 0.01. Security requires negligible advantage for every efficient distinguisher. Output that looks irregular is only preliminary evidence.

构造题的思路。两个独立种子的输出做 XOR 时，可以用 混合论证（Hybrid Argument） 先把其中一串换成均匀随机串。均匀串与独立值异或后仍均匀。遇到拼接构造，检查某两个位置是否总相等，或所有片段异或是否固定。这些可以成为设计区分实验的条件。

How to analyze a construction. For XOR of outputs from independent seeds, a hybrid argument first replaces one output with a uniform string. A uniform string XORed with an independent value stays uniform. With concatenation, look for repeated fields or a fixed XOR over the pieces. Such relationships can define distinguishing tests.

一次性语义安全（One-Time Semantic Security） 让对手提交两条等长消息，挑战者随机加密其中一条，对手猜选择位。若伪随机掩码可替换为均匀随机串而不被高效区分，剩下就是 OTP 实验。L02 将它推广到同一密钥下的多次查询。

For one-time semantic security, an adversary supplies two equal-length messages. The challenger encrypts one selected at random and the adversary guesses which. If the mask can be replaced by a uniform string without efficient detection, the remaining experiment is an OTP. L02 extends this to multiple queries using one key.

nonce、计数器和熵

Nonces, counters and entropy

流密码可以从密钥、nonce（一次性值） 和计数器生成密钥流。nonce 一般可以公开，具体要求取决于方案。同一密钥与相同 nonce/计数器输入通常产生相同掩码。讲义用 RC4 说明密钥流复用和统计偏差，再介绍 Salsa20 与 ChaCha20。

A stream cipher can generate a keystream from a key, a nonce and a counter. A nonce is usually public, with requirements depending on the scheme. Reusing the key and nonce or counter inputs normally repeats the mask. The slides use RC4 to illustrate reuse and statistical bias, then introduce Salsa20 and ChaCha20.

随机数生成器（Random Number Generator, RNG） 需要合适的起点。系统收集不可预测的 熵（Entropy），再更新内部状态。密码学安全生成器（CSPRNG） 让观察输出的人难以预测后续输出。模拟会故意用固定种子重现结果，生成密钥时则需要不可预测的状态。

A random number generator (RNG) needs a suitable starting point. The system collects unpredictable entropy and updates its state. A cryptographically secure generator (CSPRNG) makes future output hard to predict from observations. Simulations can intentionally reuse a seed for reproducibility. Key generation requires unpredictability.

模运算和线性同余

Modular arithmetic and linear congruence

取模（Modulo） 保留余数。19 mod 7 = 5，因为 19 = 2×7+5。19 ≡ 5 (mod 7) 表示二者 同余（Congruent）。模运算中的和与积可以逐步约减到小数值。

Modulo keeps the remainder. 19 mod 7 = 5 because 19 = 2×7+5. The notation 19 ≡ 5 (mod 7) means the numbers are congruent. You can reduce intermediate sums and products to smaller residues.

平方取中法（Middle-Square Method） 将定长状态平方并取中间位。零状态将一直给出零，其他状态也可能很快重复。线性同余生成器（LCG） 用 Zₙ₊₁=(aZₙ+c) mod m 更新。取 m=16、a=5、c=3、Z₀=7，第一项是 (5×7+3) mod 16 = 6，然后是 1、8。任意时刻知道当前状态就能算下一项。

The middle-square method squares a fixed-width state and keeps the middle digits. State zero stays zero, and other states can also cycle quickly. A linear congruential generator (LCG) updates Zₙ₊₁=(aZₙ+c) mod m. With m=16, a=5, c=3 and Z₀=7, the next state is (5×7+3) mod 16 = 6, followed by 1 and 8. Knowing the current state determines the next one.

全周期（Full Period） 指一轮访问全部 m 个状态。Hull–Dobell 条件要求 c 与 m 互质，m 的质因子都整除 a−1，且当 4 整除 m 时，4 也整除 a−1。上面的参数符合条件，所以可以走完 16 个状态。c=0 时是乘法型生成器，零不能离开零。周期长、输出均匀和别人难以预测是不同要求。

A full period visits all m states. The Hull–Dobell conditions require c and m to be coprime, every prime factor of m to divide a−1, and a−1 to be divisible by 4 when m is. The example meets these conditions and visits all 16 states. With c=0 the generator is multiplicative, and zero stays zero. A long period, uniform output and unpredictability are distinct properties.
