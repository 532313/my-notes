公钥密码与数字签名

Public-key cryptography and digital signatures

Diffie–Hellman 如何得到同一个值

How Diffie–Hellman yields a shared value

ElGamal, DH and randomness

Diffie–Hellman 密钥交换（DH Key Exchange） 的公开参数是生成元 g 和模数 p 等。Alice 留下秘密 a，发送 A=gᵃ mod p。Bob 留下秘密 b，发送 B=gᵇ mod p。Alice 用 B 和 a 算 Bᵃ，Bob 用 A 和 b 算 Aᵇ，两边都得到 gᵃᵇ mod p。真实协议通常再从共享值派生密钥。

Diffie–Hellman (DH) key exchange uses public parameters such as a generator g and modulus p. Alice keeps a secret a and sends A=gᵃ mod p. Bob keeps b and sends B=gᵇ mod p. Alice computes Bᵃ and Bob computes Aᵇ. Both obtain gᵃᵇ mod p. A real protocol normally derives usable keys from the shared value.

手算例。取 p=23、g=5、a=6、b=15。得到 A=8、B=19，两边算得 2。指数很大时用 平方乘法（Square-and-Multiply），先算 g、g²、g⁴、g⁸ 的余数，按指数的二进制位选取相乘，用到哪一步就在哪一步取模。

Worked example. With p=23, g=5, a=6 and b=15, A=8 and B=19, and the common result is 2. For large exponents, use square-and-multiply. Find the residues of g, g², g⁴, g⁸ and so on, multiply the powers selected by the binary exponent, and reduce after each operation.

群（Group） 需要封闭、结合律、单位元和逆元。模 p 的非零余数在乘法下构成一个群，讲义用 生成元（Generator） 的幂来遍历这个群。更一般的 DH 可在合适的子群里做。欧拉函数（Euler’s Totient Function） φ(n) 计数与 n 互质的余数，若 p 是质数则 φ(p)=p−1。

A group has closure, associativity, an identity and inverses. Nonzero residues modulo prime p form a multiplicative group, and successive powers of a generator can traverse it. DH can also use a suitable subgroup. Euler's totient function φ(n) counts residues coprime to n. For a prime p, φ(p)=p−1.

困难问题 已知与目标
DLP（Discrete Logarithm Problem） 知 g 和 gᵃ，求指数 a。
CDH（Computational Diffie–Hellman） 知 g、gᵃ 和 gᵇ，求共享值 gᵃᵇ。
DDH（Decisional Diffie–Hellman） 知 g、gᵃ 和 gᵇ，判断另一个值是 gᵃᵇ 还是独立随机群元素。
Hard problem Given and sought
Discrete logarithm (DLP) Given g and gᵃ, recover a.
Computational DH (CDH) Given g, gᵃ and gᵇ, compute gᵃᵇ.
Decisional DH (DDH) Given g, gᵃ and gᵇ, decide whether another value is gᵃᵇ or an independent random group element.

难算出值和难判断某个值是不是正确答案是不同的假设。交换中的公开幂本身也无法证明对方身份，证书和签名将在 L06 补齐认证。

Computing a value and deciding whether one is correct are distinct assumptions. The exchanged powers also need evidence of identity. L06 adds signatures and certificates.

RSA 密钥生成与模幂手算

RSA key generation and modular arithmetic

  1. 取不同的大质数 p、q，设 n=pq。计算 φ(n)=(p−1)(q−1)。
  2. 选择 e，使 gcd(e,φ(n))=1。求 d=e⁻¹ mod φ(n)，验证 ed≡1 (mod φ(n))。
  3. 公钥是 (n,e)，私钥保管 d 和相关秘密参数。教科书运算 Mᵉ mod n 得 C，Cᵈ mod n 得 M。
  1. Choose distinct large primes p and q and set n=pq. Compute φ(n)=(p−1)(q−1).
  2. Choose e coprime to φ(n). Find d=e⁻¹ mod φ(n), and check ed≡1 (mod φ(n)).
  3. Publish (n,e) and keep d and related secret parameters private. Textbook encryption computes C=Mᵉ mod n, and decryption computes M=Cᵈ mod n.

手算例。p=17、q=11，得到 n=187、φ=160。e=7 时，扩展欧几里得先写 160=22×7+6、7=6+1，因此 1=23×7−160。得 d=23，并且 ed=161。若 M=88，逐步平方可得 M² mod n=77、M⁴ mod n=132。选 4+2+1 三项，(132×77×88) mod 187=11。以 d=23 解密得回 88。

Worked example. For p=17 and q=11, n=187 and φ=160. With e=7, the extended Euclidean algorithm gives 160=22×7+6 and 7=6+1, so 1=23×7−160. Thus d=23 and ed=161. For M=88, repeated squaring gives M² mod n=77 and M⁴ mod n=132. The bits 4+2+1 select (132×77×88) mod 187=11. Raising 11 to d=23 returns 88 modulo 187.

正确性的关键。ed=1+kφ(n)。若 gcd(M,n)=1，欧拉定理给出 M^φ(n)≡1，故 Mᵉᵈ≡M。若 M 可被 p 或 q 整除，分别在模 p 和模 q 下检查。余数为 0 的那一边仍是 0，非零一边用相应的有限群性质，两边再合并。例子中 88 与 n 有公因子 11，仍能正确解密。

Why decryption works. We have ed=1+kφ(n). If gcd(M,n)=1, Euler's theorem gives M^φ(n)≡1, so Mᵉᵈ≡M. If M is divisible by p or q, check the two moduli separately. A zero residue stays zero, and a nonzero residue follows the corresponding finite-group argument. Combine the results. In the example, 88 shares factor 11 with n and still decrypts correctly.

参数风险。仅知道 n 和 e 时，安全依赖正确选取参数和 RSA 反演的困难。生成质数重复会让两个模数共享因子。过小的私钥指数或异常接近的质数也会削弱安全。HW1 Q4–Q6 深入分析这两类参数问题。小公钥指数与小私钥指数承担不同风险。

Parameter risks. With only n and e public, security relies on appropriate parameters and the hardness of inverting RSA. Repeated primes can make two moduli share a factor. An unusually small private exponent or very close primes can also weaken the scheme. HW1 Q4–Q6 analyze those cases. Small public and private exponents raise different issues.

裸 RSA（Textbook RSA） 在公钥相同、明文相同时一定产生相同密文。任何人都有公钥，因此可以加密候选消息并与观察到的结果比较。HW1 Q3 用 RSA 做两字母分组的教学例子，相同明文块产生相同密文块，和 ECB 暴露模式是一个道理。

Textbook RSA produces the same ciphertext for the same key and message. Since the public key is available, anyone can encrypt candidates and compare the results with an observed ciphertext. HW1 Q3 uses RSA with two-letter blocks to illustrate the same repeated-block pattern as ECB.

讲义用 OpenSSL 的密钥和加解密示意区分公钥文件、私钥文件和密文。查看时可认出 n、e 可公开，d、p、q 要保管。导出公钥只包含公开部分。

The slides use OpenSSL examples to distinguish public-key files, private-key files and ciphertexts. Recognize n and e as public, with d, p and q kept secret. Exporting a public key includes only public components.

OAEP（Optimal Asymmetric Encryption Padding） 先用随机种子和掩码编码，再对编码的整数做 RSA 运算。相同数据可得到不同编码。接收方要完整检查编码。讲义另介绍 PKCS #1 v1.5 的历史格式。实际长消息可做 混合加密（Hybrid Encryption），用公钥方案保护一把随机对称密钥，再用对称认证加密处理正文。

OAEP (Optimal Asymmetric Encryption Padding) encodes data using a random seed and masks before applying the RSA operation to the resulting integer. Repeated messages can have different encodings. The receiver performs the full encoding check. The slides also discuss the historical PKCS #1 v1.5 format. For long messages, hybrid encryption can protect a random symmetric key with a public-key mechanism and use symmetric authenticated encryption for the data.

ElGamal 的随机掩码和可塑性

ElGamal randomness and malleability

ElGamal, DH and randomness

  • 2024–25 Q5 (PDF p. 7)

接收者私钥为 x、公钥为 Y=gˣ。发送者选新鲜随机数 k，计算 B=gᵏ 及 X=M·Yᵏ。接收者利用 Bˣ=Yᵏ 消去共享因子。两端用的是同一群的乘法，明文要先编码为群元素。

The recipient has private x and public Y=gˣ. The sender picks fresh random k and sends B=gᵏ and X=M·Yᵏ. The recipient uses Bˣ=Yᵏ to remove the shared factor. Both use multiplication in the same group, and the message is encoded as a group element.

手算例。模 11，g=2、x=5 得 Y=10。对消息 7 取 k=3，B=8，掩码 Yᵏ=10，X=7×10 mod 11=4。接收者做 B⁵ mod 11=10，10 的逆元为 10，解出 4×10 mod 11=7。

Worked example. Modulo 11, g=2 and x=5 give Y=10. For message 7 and k=3, B=8, the mask Yᵏ=10, and X=7×10 mod 11=4. The recipient computes B⁵ mod 11=10. Its inverse is 10, giving 4×10 mod 11=7.

同一 k 会重复同一掩码。判断掩码能否和随机值区分时，要说明使用的群和 DDH 等假设。可塑性（Malleability） 是指密文能发生一种结构性变化，使解密结果也按相关方式变化。裸 ElGamal 有乘法结构，保密性和抵抗主动修改要分别分析。选择密文安全（Chosen-Ciphertext Attack Security, CCA Security） 还考虑对手获得某些解密结果的情形。

Using the same k repeats the mask. Indistinguishability from randomness depends on the chosen group and assumptions such as DDH. Malleability means that a structural change to the ciphertext yields a related change to the decrypted value. Textbook ElGamal has a multiplicative structure, so confidentiality and resistance to active tampering need separate analysis. Chosen-ciphertext attack (CCA) security also considers access to certain decryption results.

离散对数求解与 CRT

Discrete-log methods and the CRT

小步大步法（Baby-Step Giant-Step） 把指数拆为 iN+j。先存一张小步表，再用大步去找匹配项，使时间与存储大体和群阶的平方根同阶。Pohlig–Hellman 利用群阶的因子结构，把问题放进较小阶的子群分别求解，再用 中国剩余定理（Chinese Remainder Theorem, CRT） 合并。

Baby-step giant-step writes an exponent as iN+j. It stores small powers and uses giant steps to find a match, using time and storage on the order of the square root of the group order. Pohlig–Hellman uses the factors of the group order to solve smaller subgroup problems, then combines their answers using the Chinese remainder theorem (CRT).

CRT 练习。找 x，使得 x mod 3=2、x mod 5=3、x mod 7=2。第一个和第三个条件给出 x≡2 (mod 21)，候选是 2、23、44……。第二个条件选中 23。其他解和 23 相差 3×5×7 的整数倍。

CRT exercise. Find x with x mod 3=2, x mod 5=3 and x mod 7=2. The first and third conditions give x≡2 (mod 21), so the candidates include 2, 23 and 44. The second condition selects 23. Other solutions differ from 23 by multiples of 3×5×7.

数字签名（Digital Signature） 由签名者用自己的私钥生成，验证者用签名者的公钥验签。接收方还要核对签名覆盖的消息、上下文与身份。签名可以跟明文一起发送。

A digital signature is generated with the signer's private key and checked with that signer's public key. The verifier also checks the message, context and identity covered by the signature. The signed message can remain public.

目的 Alice 要发给 Bob 时
只有 Bob 能读 Alice 用 Bob 的公钥保护消息或会话密钥。
Bob 能验证来自 Alice Alice 用自己的私钥签名，Bob 用 Alice 的公钥检查。
Goal Alice sends to Bob
Only Bob can read it Alice protects the message or session key using Bob's public key.
Bob can verify Alice sent it Alice signs with her private key. Bob checks with Alice's public key.

教科书 RSA 签名用私钥幂处理消息代表值，验签用公钥幂。但普通签名接口是验证「给定消息、签名、公钥」是否匹配。不能从教科书例子推出所有签名都能恢复消息。实际 RSA 签名会先哈希消息，再使用签名专用编码。裸 RSA 的代数关系可能破坏抗伪造。选择消息攻击（Chosen-Message Attack） 模型允许对手见到选定消息的合法签名，再要求伪造未被签过的消息。

Textbook RSA signing applies the private exponent to a message representative and verification uses the public exponent. A general signature interface checks a supplied message, signature and public key for consistency. Message recovery does not follow from this interface. Practical RSA signatures hash the message and use a signature-specific encoding. Raw RSA's algebraic structure can undermine unforgeability. In a chosen-message attack, the adversary may see signatures on selected messages and is challenged to produce a signature on a fresh one.
