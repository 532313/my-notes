链路层与网络层安全

Link-layer and network-layer security

发出去的一个包有好几种地址。链路层要找到下一跳，IP 层要把数据送到远端，端口决定包交给哪个进程。学会区分这三个目标，才能判断 ARP、IPsec、防火墙各自保护哪一段。

One packet can carry several kinds of addresses. The link layer reaches the next hop. IP reaches the remote host. Ports deliver to a process. Separating these jobs makes it easier to see where ARP, IPsec and firewalls apply.

MAC、IP 与端口

MAC addresses, IP addresses and ports

层 解决的问题 常见标记
链路层（Link Layer） 怎样把帧交给当前链路上的下一跳？ MAC 地址，以太网帧。
网络层（Network Layer） 怎样经过多个网段到达目的主机？ IPv4/IPv6 地址、路由表。
传输层（Transport Layer） 怎样到达主机上的应用进程？ TCP/UDP 端口。
Layer Question Familiar fields
Link layer How does the frame reach the next hop on this link? MAC addresses, Ethernet frame.
Network layer How does the packet cross networks to its destination host? IPv4/IPv6 addresses, routes.
Transport layer How does data reach an application process on that host? TCP or UDP ports.

路由表（Routing Table） 根据目的 IP 比较网络前缀，通常优先匹配最具体的前缀。比如 192.0.2.0/24 比默认路由 /0 更具体。若目的网段未匹配专门路由，使用默认网关。TCP 提供有序字节流与可靠传输，UDP 以数据报为单位，不自行重传或排序。

A routing table compares destination prefixes and generally prefers the most specific match. For example, 192.0.2.0/24 is more specific than the default /0. With no more specific route, use the default gateway. TCP supplies a reliable ordered byte stream. UDP carries datagrams and provides no built-in retransmission or ordering.

例子。电脑地址 192.0.2.10/24，要发数据到 203.0.113.20，默认网关是 192.0.2.1。先查路由得知下一跳是网关，再要知道网关的链路地址。以太网帧的目的 MAC 是网关，内部 IP 包的目的 IP 还是 203.0.113.20。每一跳的链路头可以更换。NAT 和隧道另外会改变或包裹 IP 头。

Example. A computer at 192.0.2.10/24 sends to 203.0.113.20 through default gateway 192.0.2.1. The routing result identifies the gateway as next hop, so the link address needed is the gateway's. The Ethernet destination is the gateway MAC while the IP destination remains 203.0.113.20. Link headers can change at every hop. NAT and tunnels can also modify or wrap IP headers.

从路由到 ARP，再到会话风险

From routing to ARP and session risks

IPv4 的 地址解析协议（Address Resolution Protocol, ARP） 把本地下一跳 IP 映射到 MAC。主机查询本地网络，取得映射后放进 ARP 缓存（ARP Cache），以后可直接使用。去远端网段时，通常查网关的 MAC。

IPv4 Address Resolution Protocol (ARP) maps an on-link next-hop IP address to a MAC address. A host queries its local network and stores the answer in an ARP cache for later use. For a remote subnet it commonly resolves the gateway's MAC.

嗅探（Sniffing） 指观察到达接口的帧。集线器向连接的多个端口复制信号。交换机学习源 MAC 与入口的关系，按目的地址转发。混杂模式（Promiscuous Mode） 让驱动交付更多已经到达接口的帧。交换机的转发行为仍限制哪些帧能到这个接口。

Sniffing observes frames that reach an interface. A hub repeats signals to multiple ports. A switch learns the relation between source MACs and incoming ports, then forwards by destination. Promiscuous mode lets a driver pass on more frames that already reach the interface. Switch forwarding still determines which frames arrive.

若缓存接受错误的 IP–MAC 绑定，ARP 欺骗（ARP Spoofing） 可能让帧走错路径。即使在局域网里，也要区分「能观察包」「能改路径」「能建立受信应用会话」。会话劫持（Session Hijacking） 针对已有会话状态。分段、验证链路绑定、保护登录凭据和验证应用对端分别作用于不同边界。HTTPS 能保护已认证会话中的数据，局域网仍可能发生中断。

If a cache accepts an incorrect mapping, ARP spoofing can send frames along the wrong path. Distinguish observing packets, changing a path, and establishing a trusted application session. Session hijacking targets existing session state. Segmentation, validation of link bindings, protection of credentials and application peer authentication protect different boundaries. HTTPS can protect data in an authenticated session while local connectivity can still be disrupted.

IPsec 的协议、模式和安全关联

IPsec protocols, modes and security associations

普通 IP 头的地址可用于路由，本身并不证明发件人。IPsec 给匹配策略的 IP 流量提供完整性、认证、防重放或保密。具体保护取决于协议和配置。

An ordinary IP source address supports routing and supplies no inherent proof of identity. IPsec can add integrity, origin authentication, replay protection or confidentiality to policy-matched IP traffic. The exact guarantees depend on the protocol and configuration.

选择 保护的内容
AH（Authentication Header） 提供数据来源认证和完整性，覆盖载荷及部分 IP 头字段，可配合防重放。载荷保持可读。
ESP（Encapsulating Security Payload） 能加密所封装的载荷，并可按配置验证完整性和防重放。外层路由头一般可读。
传输模式（Transport Mode） 沿用原 IP 头，在其后保护传输层数据等载荷。
隧道模式（Tunnel Mode） 将原 IP 包读作内部载荷，再套新的外层 IP 头到隧道端点。
Choice What it covers
AH (Authentication Header) Origin authentication and integrity for the payload and selected IP fields, with replay protection available. The payload remains readable.
ESP (Encapsulating Security Payload) Can encrypt the encapsulated payload and provide integrity and replay protection as configured. The outer routing header generally remains visible.
Transport mode Retains the original IP header and protects the transport data or other payload following it.
Tunnel mode Carries the entire original IP packet as an inner payload under a new outer IP header directed at a tunnel endpoint.

安全关联（Security Association, SA） 是一条单向流量使用的密钥、算法、标识与重放状态。双向通信需要至少两个方向的 SA。安全参数索引（SPI） 帮助找对关联。IKE（Internet Key Exchange） 负责协商。SPD（Security Policy Database） 决定流量应保护、放行或丢弃，SAD（Security Association Database） 存使用中的安全关联。

A security association (SA) holds the key, algorithm, identifiers and replay state for one direction. Two-way traffic needs an SA for each direction. The security parameters index (SPI) helps find the right one. Internet Key Exchange (IKE) negotiates associations. The Security Policy Database (SPD) decides whether to protect, allow or discard traffic. The Security Association Database (SAD) stores the active associations.

读图题。两个网关用 ESP 隧道保护内部网络。外层头指向网关，内层头指出真正的内部收发主机。接收网关找到入站 SA，按它验证和解封。向另一个方向发包要查该方向的策略与 SA。

Diagram reasoning. Two gateways protect internal networks with an ESP tunnel. Outer headers address the gateways and inner headers address the actual endpoints. The receiving gateway locates its inbound SA, verifies the packet and unwraps it. The reverse direction uses its own policy and SA.

过滤、NAT 与入侵检测

Filtering, NAT and intrusion detection

防火墙（Firewall） 在网络边界执行策略。无状态过滤（Stateless Filtering） 单独看一个包的地址、端口、协议和方向。有状态过滤（Stateful Filtering） 还记录流属于哪次连接，能按已建立状态接受返回流量。Linux 课件用 INPUT、OUTPUT、FORWARD 三种方向来区分处理点。

A firewall enforces network policy at a boundary. A stateless filter examines each packet on its own using addresses, ports, protocol and direction. A stateful filter also tracks flow state, so it can recognize return traffic for an allowed connection. The Linux example distinguishes INPUT, OUTPUT and FORWARD processing.

网络地址转换（NAT） 能重写地址和端口。UDP 没有 TCP 那样的握手，NAT 通常按自己的规则保留暂时的映射。课堂中的 STUN 帮助设备发现它在 NAT 外呈现的地址和端口。是否能互通还依赖 NAT 行为与防火墙规则。

Network address translation (NAT) can rewrite addresses and ports. Without a TCP-style handshake, UDP mappings are usually temporary and follow the NAT's own rules. The slides use STUN to help a device learn which address and port are visible outside its NAT. Connectivity still depends on NAT behavior and firewall policy.

网络入侵检测（Network Intrusion Detection, NIDS） 侧重观测和告警。特征检测（Signature-Based Detection） 查已知模式，异常检测（Anomaly-Based Detection） 查行为偏离。课件的 Snort 将包解码、预处理、匹配规则，随后记录或告警。可在交换机做 端口镜像（Port Mirroring） 让探针收到副本。是否看得到关键流量、是否因拥塞丢包、内容是否已经加密，都会影响判断。

Network intrusion detection (NIDS) observes and alerts. Signature-based detection looks for known patterns. Anomaly-based detection looks for departures from normal behavior. In the slides, Snort decodes and preprocesses packets, applies rules, then logs or alerts. A switch can use port mirroring to feed a sensor. Visibility, capture losses and encryption affect what the sensor can conclude.
