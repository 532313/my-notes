指南和已发布的笔记公开可见，可在手机、平板和电脑上直接阅读。

  1. 从左侧打开驱动开发指南，阅读时点击“记笔记”可关联当前章节。
  2. 新建或导入 Markdown / 文本笔记，支持编辑、分栏预览、分类、代码高亮和一键复制代码。阅读模式保护标题与笔记本名称，切换到编辑后可修改。
  3. 草稿自动保存在本机。连接 GitHub 后，点击“保存到 GitHub”发布；换设备后点击“同步”读取最新内容。误改时可选择“放弃本机修改”，回到最近同步的云端版本；放弃前需确认。
  4. 可导出 Markdown 备份。回收站中的笔记和 PDF 可恢复，也可单个或批量永久删除。永久删除后无法在网站中恢复，GitHub 提交历史仍保留旧版本。
  5. PDF 导入需连接 GitHub，单个文件不超过 10 MB。

多设备同时编辑时，网站会保留草稿并提示冲突，不会直接覆盖云端的新版本。
