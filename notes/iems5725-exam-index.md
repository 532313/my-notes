## 按题型练习 / Practice by question type

- **判断 / True or false** · 先判断，再说明条件、边界或一个反例。 / Give a verdict, then explain the condition, boundary, or a counterexample.

- **简答 / Short answer** · 写定义、机制、例子或取舍。对比题用相同维度。 / State the definition, mechanism, and an example or trade-off. Compare using the same dimensions.

- **长题和编程 / Long and programming questions** · 先标出调用者、输入和状态，再说明权限、更新、失败行为。 / Identify the caller, inputs, and state, then explain authorization, updates, and failure behavior.
